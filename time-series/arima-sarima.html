ARIMA y SARIMA

TipResumen en 30 segundos

ARIMA modela una serie temporal mediante tres componentes:

  • AR: dependencia de valores pasados.
  • I: diferenciación para lograr estacionariedad.
  • MA: dependencia de errores pasados.

SARIMA añade estacionalidad.

SARIMAX permite además incorporar variables externas.

¿Qué significa ARIMA?

ARIMA significa:

AutoRegressive
Integrated
Moving Average

Se representa como:

\[ ARIMA(p,d,q) \]

donde:

  • (p): orden autoregresivo.
  • (d): número de diferencias.
  • (q): orden de media móvil.
NoteIdea clave

ARIMA combina memoria de la propia serie, diferenciación y errores pasados.

Componente AR

El componente autoregresivo utiliza valores pasados.

Un AR(1) puede escribirse como:

\[ y_t = c + \phi_1 y_{t-1} + \varepsilon_t \]

Interpretación:

Valor actual
≈
constante
+
valor anterior
+
error

AR(p)

\[ y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_t \]

Componente I

La parte integrada aplica diferencias.

Primera diferencia:

\[ \Delta y_t = y_t-y_{t-1} \]

differenced = (
    series
    .diff()
    .dropna()
)

Componente MA

El componente de media móvil utiliza errores pasados.

Un MA(1) puede escribirse como:

\[ y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} \]

ARIMA completo

Un ARIMA combina:

  • Lags de la serie.
  • Diferenciación.
  • Lags de los errores.

Preparar la serie

import pandas as pd

series = (
    df
    .set_index("datetime")[
        "value"
    ]
    .sort_index()
)

Regularizar frecuencia

daily_series = (
    series
    .resample("D")
    .mean()
)

Tratar ausentes

daily_series = (
    daily_series
    .interpolate(
        method="time"
    )
)

Split temporal

train = daily_series.loc[
    daily_series.index
    <
    "2025-07-01"
]

test = daily_series.loc[
    daily_series.index
    >=
    "2025-07-01"
]

Revisar estacionariedad

from statsmodels.tsa.stattools import adfuller

adf_result = adfuller(
    train.dropna(),
    autolag="AIC"
)

print(
    adf_result[1]
)

Diferenciación

train_diff = (
    train
    .diff()
    .dropna()
)

Elegir d

Una guía práctica:

Serie estacionaria
→ d = 0

Una diferencia suficiente
→ d = 1

Dos diferencias necesarias
→ d = 2
WarningPrecaución

Valores altos de d pueden sobrediferenciar la serie.

ACF y PACF

ACF y PACF ayudan a orientar la elección de (p) y (q).

ACF

from statsmodels.graphics.tsaplots import plot_acf
import matplotlib.pyplot as plt

plot_acf(
    train_diff,
    lags=40
)

plt.show()

PACF

from statsmodels.graphics.tsaplots import plot_pacf

plot_pacf(
    train_diff,
    lags=40,
    method="ywm"
)

plt.show()

Interpretación orientativa

PACF corta tras lag p
→ posible AR(p)

ACF corta tras lag q
→ posible MA(q)

Ambas decaen
→ posible ARMA

No son reglas absolutas.

Entrenar ARIMA

from statsmodels.tsa.arima.model import ARIMA

model = ARIMA(

    order=(
        1,
        1,

    )

fitted_model = model.fit()

Resumen del modelo

print(

Forecast

forecast_result = fitted_model.get_forecast(

forecast_mean = (

Intervalo de confianza

forecast_interval = (
    forecast_result

        alpha=0.05

Selección de órdenes

Puede probarse una cuadrícula de valores.

import itertools
import pandas as pd

p_values = range(
    0,
    4
)

d_values = range(
    0,
    3
)

q_values = range(
    0,
    4
)

rows = []

for p, d, q in itertools.product(
    p_values,
    d_values,
    q_values
):

    try:

        model = ARIMA(
            train,
            order=(
                p,
                d,
                q
            )
        )

        fitted = model.fit()

        rows.append(
            {
                "p": p,
                "d": d,
                "q": q,
                "aic": fitted.aic,
                "bic": fitted.bic
            }
        )

    except Exception:

        continue

order_table = pd.DataFrame(
    rows
).sort_values(
    "aic"
)

display(
    order_table.head(10)
)

AIC y BIC

Valores menores suelen ser preferibles.

Pero la selección final debe basarse también en:

  • Backtesting.
  • Estabilidad.
  • Residuos.
  • Interpretabilidad.
  • Error por horizonte.

Residuos ideales

  • Ausencia de estructura clara.

SARIMA

SARIMA añade una componente estacional.

Se representa como:

\[ SARIMA(p,d,q)(P,D,Q)_s \]

donde:

  • (P): orden AR estacional.
  • (D): diferenciación estacional.
  • (Q): orden MA estacional.
  • (s): periodo estacional.

Ejemplo semanal

Con datos diarios y ciclo semanal:

s = 7

SARIMAX

En statsmodels, SARIMA se implementa mediante SARIMAX.

from statsmodels.tsa.statespace.sarimax import SARIMAX

model = SARIMAX(
    train,
    order=(
        1,
        1,
        1
    ),
    seasonal_order=(
        1,
        1,
        1,
        7
    ),
    enforce_stationarity=False,
    enforce_invertibility=False
)

fitted_model = model.fit(
    disp=False
)

Forecast SARIMA

forecast_result = fitted_model.get_forecast(
    steps=len(test)
)

forecast_mean = (
    forecast_result
    .predicted_mean
)

forecast_interval = (
    forecast_result
    .conf_int()
)

Diferenciación estacional

\[ \Delta_s y_t = y_t-y_{t-s} \]

seasonal_difference = (
    train
    .diff(
        7
    )
    .dropna()
)

Elegir D

Sin estacionalidad no estacionaria
→ D = 0

Una diferencia estacional suficiente
→ D = 1

ACF estacional

Picos en:

lag 7
lag 14
lag 21

pueden sugerir estructura semanal.

SARIMAX con variables externas

SARIMAX puede incorporar variables exógenas.

Ejemplos:

  • Festivos.
  • Temperatura.
  • Intervenciones.
  • Día de la semana.
  • Cambios de protocolo.
  • Tratamientos.

Preparar exógenas

exogenous_features = [
    "is_weekend",
    "holiday",
    "temperature"
]

X_train = train_df[
    exogenous_features
]

X_test = test_df[
    exogenous_features
]

Entrenar SARIMAX

model = SARIMAX(
    train_df["target"],
    exog=X_train,
    order=(
        1,
        1,
        1
    ),
    seasonal_order=(
        1,
        1,
        1,
        7
    ),
    enforce_stationarity=False,
    enforce_invertibility=False
)

fitted_model = model.fit(
    disp=False
)

Forecast con exógenas

forecast_result = fitted_model.get_forecast(
    steps=len(test_df),
    exog=X_test
)

Requisito clave

Para predecir el futuro deben conocerse también los valores futuros de las variables externas.

Festivo futuro
→ conocido

Temperatura futura
→ requiere forecast o escenario

Tratamiento futuro
→ puede no conocerse
WarningImportante

No incluyas variables exógenas futuras que no estarán disponibles en producción.

Variables de intervención

Puede modelarse un cambio de protocolo.

df[
    "post_protocol_change"

    )
).astype(int)

Variable pulso

df[
    "special_event"
] = (
    df.index
    ==
    pd.Timestamp(
        "2025-03-15"
    )
).astype(int)

Regresión con errores ARIMA

SARIMAX puede interpretarse como:

Regresión con variables externas
+
estructura temporal en los errores

Backtesting

La selección debe evaluarse en varios cortes temporales.

forecast_horizon = 7

rows = []

for cutoff in range(
    100,
    len(daily_series)
    -
    forecast_horizon,
    7
):

    train_fold = daily_series.iloc[
        :cutoff
    ]

    test_fold = daily_series.iloc[
        cutoff:
        cutoff
        +
        forecast_horizon
    ]

    model = SARIMAX(
        train_fold,
        order=(
            1,
            1,
            1
        ),
        seasonal_order=(
            1,
            1,
            1,
            7
        ),
        enforce_stationarity=False,
        enforce_invertibility=False
    )

    fitted = model.fit(
        disp=False
    )

    forecast = fitted.forecast(
        steps=forecast_horizon
    )

    rows.append(
        {
            "cutoff": train_fold.index[-1],
            "mae": mean_absolute_error(
                test_fold,
                forecast
            )
        }
    )

Error por horizonte

horizon_errors = {
    horizon: []
    for horizon in range(
        1,
        8
    )
}

Debe analizarse si el modelo funciona bien:

  • A corto plazo.
  • A medio plazo.
  • En todos los periodos.
  • Solo durante periodos estables.

Actualización del modelo

ARIMA puede actualizarse al recibir nuevos datos.

Opciones:

  • Reentrenar completamente.
  • Actualizar estado.
  • Usar ventana móvil.
  • Reestimar periódicamente.

Cambio estructural

ARIMA y SARIMA pueden fallar ante:

  • Cambio de protocolo.
  • Pandemia.
  • Nueva tecnología.
  • Cambio de población.
  • Ruptura de tendencia.

Puede ser necesario añadir:

  • Variables de intervención.
  • Ventanas móviles.
  • Retraining.
  • Modelos de régimen.

Supuesto de linealidad

ARIMA modela relaciones lineales con el pasado.

Puede no capturar:

  • Umbrales.
  • Interacciones complejas.
  • Cambios abruptos.
  • Relaciones no lineales.

Ventajas

  • Interpretables.
  • Bien establecidos.
  • Útiles con autocorrelación.
  • Permiten intervalos.
  • SARIMA maneja estacionalidad.
  • SARIMAX incorpora variables externas.
  • Buenos baselines clásicos.

Limitaciones

  • Requieren frecuencia regular.
  • Sensibles a especificación.
  • Pueden ser costosos al buscar órdenes.
  • No manejan fácilmente múltiples series.
  • Asumen estructura lineal.
  • Dificultad con varias estacionalidades.
  • Sensibles a cambios estructurales.

Consideraciones clínicas

NoteAplicación clínica

ARIMA y SARIMA suelen ser más adecuados para series agregadas o señales regulares que para seguimientos clínicos muy irregulares.

Ejemplos:

  • Demanda asistencial diaria.
  • Ocupación de camas.
  • Volumen de urgencias.
  • Consumo de recursos.
  • Señales fisiológicas regulares.
  • Biomarcadores agregados por periodo.

Errores frecuentes

  • No revisar estacionariedad.
  • Elegir órdenes solo por ACF/PACF.
  • Elegir modelo solo por AIC.
  • No comparar con naive.
  • No revisar residuos.
  • Ignorar estacionalidad.
  • Usar exógenas futuras desconocidas.
  • No hacer backtesting.
  • Sobrediferenciar.
  • Usar demasiados parámetros.
  • Ignorar cambios estructurales.
  • No evaluar intervalos.

Flujo recomendado

  1. Visualizar la serie.
  2. Revisar estacionariedad.
  3. Definir d.
  4. Revisar ACF y PACF.
  5. Probar órdenes pequeños.
  6. Comparar AIC y BIC.
  7. Aplicar backtesting.
  8. Revisar residuos.
  9. Añadir estacionalidad si procede.
  10. Considerar exógenas.
  11. Evaluar intervalos.
  12. Comparar con naive.
