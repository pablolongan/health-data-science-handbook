Selección de variables y regularización

TipResumen en 30 segundos

La selección de variables busca conservar las características más útiles para el modelo.

La regularización reduce la complejidad penalizando coeficientes grandes.

Ambas técnicas pueden ayudar a:

  • Reducir overfitting.
  • Mejorar interpretabilidad.
  • Disminuir coste computacional.
  • Eliminar ruido.
  • Construir modelos más estables.

Objetivo de esta sección

En muchos proyectos existen más variables de las necesarias.

Algunas pueden ser:

  • Redundantes.
  • Irrelevantes.
  • Muy correlacionadas.
  • Inestables.
  • Difíciles de obtener.
  • Costosas clínicamente.
  • Potencialmente relacionadas con leakage.

El objetivo no es eliminar variables por sistema, sino encontrar una representación:

  • Predictiva.
  • Estable.
  • Interpretativa.
  • Reproducible.
  • Clínicamente coherente.
NoteIdea clave

Más variables no significa necesariamente mejor modelo.

Selección de variables frente a reducción de dimensionalidad

Selección de variables

Conserva un subconjunto de las variables originales.

Ejemplo:

Edad
Troponina
FEVI
GLS

Ventajas:

  • Mantiene interpretabilidad.
  • Facilita explicar el modelo.
  • Permite identificar variables relevantes.

Reducción de dimensionalidad

Crea nuevas variables combinando las originales.

Ejemplo:

Componente principal 1
Componente principal 2

Ventajas:

  • Puede resumir información.
  • Reduce colinealidad.
  • Puede mejorar eficiencia.

Limitación:

  • Las nuevas variables pueden ser difíciles de interpretar.

Familias de métodos

Métodos filter

Evalúan cada variable utilizando criterios estadísticos antes de entrenar el modelo final.

Ejemplos:

  • Correlación.
  • Chi-cuadrado.
  • ANOVA.
  • Mutual information.
  • Variance threshold.

Métodos wrapper

Evalúan subconjuntos de variables entrenando repetidamente un modelo.

Ejemplos:

  • Recursive Feature Elimination.
  • Sequential Feature Selection.
  • Forward selection.
  • Backward elimination.

Métodos embedded

La selección ocurre durante el entrenamiento.

Ejemplos:

  • Lasso.
  • Elastic Net.
  • Árboles.
  • Random forest.
  • Gradient boosting.

Regularización

Penaliza modelos excesivamente complejos.

Ejemplos:

  • Ridge.
  • Lasso.
  • Elastic Net.

Riesgo de data leakage

La selección de variables debe aprenderse solo con train.

Ejemplo incorrecto

from sklearn.feature_selection import SelectKBest
from sklearn.feature_selection import f_classif

selector = SelectKBest(
    score_func=f_classif,
    k=20
)

X_selected = selector.fit_transform(
    X,
    y
)

scores = cross_val_score(
    model,
    X_selected,
    y,
    cv=5
)

Aquí la selección utiliza todo el dataset antes de la validación cruzada.

Ejemplo correcto

from sklearn.pipeline import Pipeline
from sklearn.feature_selection import SelectKBest
from sklearn.feature_selection import f_classif

pipeline = Pipeline(
    steps=[
        (
            "preprocessor",
            preprocessor
        ),
        (
            "selector",
            SelectKBest(
                score_func=f_classif,
                k=20
            )
        ),
        (
            "model",
            model
        )
    ]
)

scores = cross_val_score(
    pipeline,
    X,
    y,
    cv=5
)
WarningImportante

La selección de variables debe repetirse dentro de cada fold.

Variables irrelevantes

Una variable irrelevante no aporta información útil para predecir el target.

Puede:

  • Introducir ruido.
  • Aumentar varianza.
  • Dificultar interpretación.
  • Incrementar coste computacional.

Variables redundantes

Dos variables pueden aportar información muy parecida.

Ejemplos:

  • Peso y superficie corporal.
  • Dos medidas muy correlacionadas.
  • Códigos duplicados.
  • Variables derivadas de otras.

Esto puede generar:

  • Multicolinealidad.
  • Inestabilidad de coeficientes.
  • Interpretación confusa.

Multicolinealidad

La multicolinealidad aparece cuando varias variables predictoras están fuertemente relacionadas.

Puede afectar especialmente a modelos lineales.

Consecuencias:

  • Coeficientes inestables.
  • Signos inesperados.
  • Intervalos amplios.
  • Dificultad de interpretación.

Matriz de correlación

correlation_matrix = (
    X_train[
        numeric_features
    ]
    .corr()
)

display(
    correlation_matrix
)

Identificar correlaciones altas

import numpy as np

upper_triangle = (
    correlation_matrix
    .where(
        np.triu(
            np.ones(
                correlation_matrix.shape
            ),
            k=1
        ).astype(bool)
    )
)

high_correlations = [
    column
    for column in upper_triangle.columns
    if any(
        upper_triangle[column]
        .abs()
        > 0.90
    )
]

print(
    high_correlations
)
CautionPrecaución

No elimines automáticamente una variable solo por alta correlación.

Puede tener mayor calidad, interpretabilidad o disponibilidad clínica.

Número de variables y tamaño de muestra

Un modelo con muchas variables y pocos pacientes tiene mayor riesgo de overfitting.

Conviene revisar:

  • Número de observaciones.
  • Número de eventos.
  • Número de variables.
  • Complejidad del modelo.
  • Estabilidad de la selección.

Selección y estabilidad

Una variable puede aparecer seleccionada en un fold y no en otro.

Eso puede indicar:

  • Muestra pequeña.
  • Variables correlacionadas.
  • Señal débil.
  • Modelo inestable.

Frecuencia de selección

selection_counts = {
    feature: 0
    for feature in feature_names
}

Después de cada fold puede incrementarse el contador de las variables seleccionadas.

Las variables elegidas de forma consistente suelen ser más fiables.

Interpretabilidad clínica

NoteAplicación clínica

Una variable puede ser predictiva pero poco útil si:

  • No está disponible en el momento de predicción.
  • Es costosa.
  • Es invasiva.
  • Tiene mucha ausencia.
  • No se mide en otros centros.

Coste de adquisición

La selección también puede considerar:

  • Coste económico.
  • Tiempo.
  • Invasividad.
  • Carga para el paciente.
  • Disponibilidad.
  • Reproducibilidad.

Un modelo ligeramente peor pero mucho más simple puede ser más útil.

Importancia predictiva frente a causalidad

Una variable seleccionada no es necesariamente causal.

Puede ser:

  • Marcador.
  • Proxy.
  • Confusor.
  • Consecuencia del proceso.
  • Indicador del centro.
WarningImportante

Feature importance no equivale a efecto causal.

Selección supervisada y no supervisada

Supervisada

Utiliza el target.

Ejemplos:

  • ANOVA.
  • Chi-cuadrado.
  • Mutual information.
  • Lasso.
  • RFE.

No supervisada

No utiliza el target.

Ejemplos:

  • Variance threshold.
  • Correlación entre predictores.
  • PCA.

Flujo recomendado

  1. Definir la pregunta.
  2. Excluir identificadores y leakage.
  3. Revisar calidad de variables.
  4. Revisar valores ausentes.
  5. Revisar redundancia.
  6. Elegir familia de selección.
  7. Integrar selección en pipeline.
  8. Validar con cross-validation.
  9. Evaluar estabilidad.
  10. Comparar con modelo sin selección.
  11. Revisar interpretabilidad clínica.
  12. Documentar variables finales.

Qué comparar

Siempre conviene comparar:

Modelo sin selección
vs
Modelo con selección

Debe evaluarse:

  • Rendimiento.
  • Variabilidad.
  • Número de variables.
  • Interpretabilidad.
  • Coste.
  • Estabilidad.

Errores frecuentes

  • Seleccionar variables con todo el dataset.
  • Elegir variables por p-value sin validación.
  • Confundir correlación con causalidad.
  • Eliminar variables correlacionadas automáticamente.
  • Usar importancias de árboles como verdad absoluta.
  • No escalar antes de Lasso o Ridge.
  • No comparar con el modelo completo.
  • Ignorar estabilidad entre folds.
  • Seleccionar demasiadas variables.
  • Usar información futura.
