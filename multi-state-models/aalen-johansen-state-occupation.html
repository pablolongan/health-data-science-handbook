Aalen-Johansen y ocupación de estados

TipResumen en 30 segundos

El estimador de Aalen-Johansen es la extensión natural de Kaplan-Meier a procesos multiestado.

Permite estimar:

  • Probabilidades de transición.
  • Probabilidades de ocupación de estado.
  • Incidencias acumuladas en competing risks.
  • Evolución no paramétrica del proceso.

No exige intensidades constantes ni una distribución paramétrica concreta.

¿Qué estima Aalen-Johansen?

Para un proceso con estados (r) y (s), estima:

\[ P_{rs}(u,t) = P[ X(t)=s \mid X(u)=r ] \]

Es decir, la probabilidad de estar en el estado (s) en el tiempo (t), partiendo del estado (r) en el tiempo (u).

NoteIdea clave

Kaplan-Meier estima permanencia libre de un evento; Aalen-Johansen estima movimiento entre varios estados.

Relación con competing risks

Un modelo de competing risks es un multiestado simple:

Estado 0
├──→ Evento 1
└──→ Evento 2

Aalen-Johansen estima la incidencia acumulada de cada destino.

Relación con Kaplan-Meier

Con solo dos estados:

0 → 1

y estado 1 absorbente, Aalen-Johansen coincide con Kaplan-Meier para la supervivencia correspondiente.

Product integral

El estimador se basa en el producto integral:

\[ \hat{P}(u,t) = \prod_{(u,t]} [ I+d\hat{A}(v) ] \]

donde:

  • (I): matriz identidad.
  • ((v)): matriz de intensidades acumuladas estimadas.
  • (d(v)): incrementos en tiempos de transición.

Matriz de incrementos

Para cada tiempo de transición:

\[ d\hat{A}_{rs}(t) = \frac{ dN_{rs}(t) }{ Y_r(t) } \]

donde:

  • (dN_{rs}(t)): transiciones observadas (r s).
  • (Y_r(t)): personas en riesgo en (r) justo antes de (t).

Diagonal

\[ d\hat{A}_{rr}(t) = - \sum_{s\neq r} d\hat{A}_{rs}(t) \]

Interpretación

En cada tiempo de evento se actualiza la matriz de transición acumulada.

De competing risks a multiestado

En un modelo general:

S0 ↔ S1 ↔ S2 → S3

Aalen-Johansen estima matrices de transición entre todos los estados.

Risk set por estado

En cada tiempo (t), debe contarse quién está en cada estado justo antes del tiempo.

Función conceptual

def at_risk_in_state(
    data,
    state,
    time
):

    return data.loc[
        (
            data[
                "from_state"
            ]
            ==
            state
        )
        &
        (
            data[
                "start"
            ]
            <
            time
        )
        &
        (
            data[
                "stop"
            ]
            >=
            time
        )
    ]

Incremento de A

def cumulative_hazard_increment(
    data,
    states,
    time
):

    dA = np.zeros(
        (
            len(
                states
            ),
            len(
                states
            )
        )
    )

    for origin in states:

        origin_index = state_to_index[
            origin
        ]

        risk_set = at_risk_in_state(
            data,
            origin,
            time
        )

        y_r = len(
            risk_set
        )

        if y_r == 0:
            continue

        events_at_time = data.loc[
            (
                data[
                    "from_state"
                ]
                ==
                origin
            )
            &
            (
                data[
                    "status"
                ]
                ==
                1
            )
            &
            (
                data[
                    "stop"
                ]
                ==
                time
            )
        ]

        for destination in states:

            if destination == origin:
                continue

            destination_index = state_to_index[
                destination
            ]

            d_n = (
                events_at_time[
                    "to_state"
                ]
                ==
                destination
            ).sum()

            dA[
                origin_index,
                destination_index
            ] = (
                d_n
                /
                y_r
            )

        dA[
            origin_index,
            origin_index
        ] = (
            -
            dA[
                origin_index,
                :
            ].sum()
        )

    return dA

Actualizar product integral

transition_matrices = []

for time in event_times:

    dA = cumulative_hazard_increment(
        data=interval_data,
        states=states,
        time=time
    )

    P = (
        P
        @
        (
            np.eye(
                len(
                    states
                )
            )
            +
            dA
        )
    )

    transition_matrices.append(
        {
            "time": time,
            "P": P.copy()
        }
    )

Interpretación

P(S2 a 1 año) = 0.12

significa que un 12 % de la cohorte se espera que esté en S2 al año, bajo la distribución inicial elegida.

Ocupación no es incidencia acumulada

Un paciente puede:

S0 → S1 → S0

Entonces:

  • Ha experimentado S1.
  • Pero puede no estar en S1 en el horizonte.

Diferencia

Incidencia acumulada de haber alcanzado S1
≠
probabilidad de ocupar S1 en t

Estado reversible

La ocupación puede subir y después bajar.

Estado absorbente

La probabilidad de ocupación solo puede aumentar o mantenerse.

Ejemplo:

S3 absorbente

Probabilidad de haber alcanzado un estado

Puede requerir:

  • Estado absorbente auxiliar.
  • Transformación del modelo.
  • Análisis de first passage.
  • Simulación.

First passage probability

Pregunta:

¿Cuál es la probabilidad
de alcanzar S2 antes de 2 años?

No es necesariamente igual a:

P(estar en S2 a 2 años)

porque el paciente podría haber regresado a S1.

Estado auxiliar

Puede crearse:

Ever_S2

como estado absorbente para analizar primera llegada.

Probabilidad condicional desde un landmark

Si un paciente está en S1 en el mes 6:

P(S2 en mes 12 | S1 en mes 6)

corresponde a:

\[ P_{12}(6,12) \]

Landmark

u = 6 meses
t = 12 meses

Matriz entre dos tiempos

En un modelo no homogéneo, debe estimarse el product integral entre (u) y (t), no desde 0.

Distribución inicial observada

No todos los pacientes tienen que empezar en S0.

Bootstrap por paciente

Para obtener intervalos:

  1. Re-muestrear pacientes.
  2. Reconstruir trayectorias completas.
  3. Recalcular Aalen-Johansen.
  4. Extraer probabilidades.
  5. Repetir.

Ejemplo conceptual

rng = np.random.default_rng(
    42
)

patient_ids = interval_data[
    "patient_id"
].unique()
bootstrap_occupancy = []

for iteration in range(
    1000
):

    sampled_ids = rng.choice(
        patient_ids,
        size=len(
            patient_ids
        ),
        replace=True
    )

    sampled_data = pd.concat(
        [
            interval_data.loc[
                interval_data[
                    "patient_id"
                ]
                ==
                patient_id
            ]
            .assign(
                bootstrap_patient_id=(
                    f"{iteration}_{sample_index}"
                )
            )
            for sample_index, patient_id
            in enumerate(
                sampled_ids
            )
        ],
        ignore_index=True
    )

    estimate = estimate_occupancy(
        sampled_data

Soporte temporal

No debe interpretarse más allá del seguimiento observado.

Panel data

Aalen-Johansen estándar presupone conocer tiempos de transición con suficiente precisión.

Con estados observados solo en visitas:

S0 en día 0
S2 en día 100

la transición exacta es incierta.

Limitación

Asignar el cambio al día 100 puede sesgar:

  • Intensidades.
  • Ocupación.
  • Tiempo en estado.

Alternativas

  • Punto medio.
  • Sensitivity analysis.
  • Modelo Markov de panel.
  • Hidden Markov Model.
  • Censura por intervalo.

Delayed entry

El risk set debe incluir a cada paciente solo desde su entrada.

Censura independiente

Se asume que, condicionado a la información disponible, la censura no depende del proceso futuro de forma informativa.

Censura informativa

Ejemplo:

Pacientes graves
→ pierden seguimiento con mayor frecuencia

Puede sesgar las probabilidades.

IPCW

Puede considerarse ponderación por probabilidad inversa de censura cuando existe un modelo razonable de censura.

Estados mal clasificados

Aalen-Johansen trata los estados observados como correctos.

Si existe error relevante, puede ser preferible un Hidden Markov Model.

Frecuencia de visitas

Los grupos con más evaluaciones pueden mostrar transiciones antes.

Esto afecta especialmente a estados derivados de pruebas.

Ajuste por covariables

Aalen-Johansen es principalmente descriptivo.

Para ajuste pueden utilizarse:

  • Cox por transición.
  • Pseudo-observations.
  • Standardization.
  • Modelos Markov con covariables.
  • Modelos de landmark.

Standardized state occupation

Conceptualmente:

  1. Ajustar modelos por transición.
  2. Predecir para todos bajo un escenario.
  3. Promediar probabilidades.
  4. Comparar escenarios.

Riesgo causal

Una diferencia ajustada no es causal sin supuestos adicionales.

Interpolación escalonada

Las probabilidades son funciones escalonadas.

Para obtener el último valor antes de un horizonte:

def step_value_at_time(
    times,
    values,
    horizon
):

    valid = (
        times
        <=
        horizon
    )

    if not valid.any():
        return values[
            0
        ]

    return values[
        valid
    ][
        -1
    ]

Paso constante

Como la curva es escalonada, una integración por tramos puede ser más exacta.

def integrate_step_function(
    times,
    values,
    horizon
):

    total = 0.0

    for index in range(
        len(
            times
        )
        -
        1
    ):

        start = times[
            index
        ]

        stop = min(
            times[
                index
                +
                1
            ],
            horizon
        )

        if stop <= start:
            continue

        total += (
            values[
                index
            ]
            *
            (
                stop
                -
                start
            )
        )

        if stop == horizon:
            break

    return total

Ejemplo de redacción

Las probabilidades de ocupación de estado
se estimaron mediante Aalen-Johansen.

A los 12 meses,
la probabilidad de permanecer en S0 fue del 68 %,
mientras que las probabilidades de ocupar
S1, S2 y S3 fueron del 19 %, 10 % y 3 %.

Errores frecuentes

  • Usar Kaplan-Meier para varios destinos.
  • Confundir ocupación e incidencia acumulada.
  • Interpretar más allá del seguimiento.
  • Ignorar pocos pacientes en la cola.
  • No indicar estado inicial.
  • No considerar delayed entry.
  • Tratar panel data como observación exacta.
  • Ignorar error de clasificación.
  • Comparar grupos como si estuvieran ajustados.
  • No re-muestrear por paciente.
  • No validar que las filas suman 1.
  • Confundir haber alcanzado un estado con ocuparlo.

Flujo recomendado

  1. Definir estados.
  2. Preparar intervalos.
  3. Identificar risk sets.
  4. Calcular incrementos.
  5. Construir product integral.
  6. Estimar matrices.
  7. Calcular ocupación.
  8. Añadir incertidumbre.
  9. Comparar con Markov.
  10. Resumir horizontes.
  11. Calcular tiempo en estado.
  12. Comunicar resultados.
