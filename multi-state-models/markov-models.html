Modelos de Markov multiestado

TipResumen en 30 segundos

Un modelo de Markov multiestado asume que el futuro depende del estado actual, no de toda la trayectoria previa.

Formalmente:

\[ P[ X(t+\Delta)=s \mid X(t)=r,\text{historia previa} ] = P[ X(t+\Delta)=s \mid X(t)=r ] \]

A partir de una matriz de intensidades (Q) pueden calcularse probabilidades de transición, ocupación de estados y tiempos esperados.

¿Qué es la propiedad de Markov?

La propiedad de Markov establece que el estado actual resume toda la información necesaria para predecir el siguiente cambio.

NoteIdea clave

En un modelo Markov, importa dónde está el paciente ahora, no cómo llegó hasta ahí.

Ejemplo clínico

Dos pacientes están actualmente en S1.

Paciente A:

S0 → S1

Paciente B:

S2 → S1

Un modelo Markov puro asume que ambos tienen el mismo riesgo futuro si comparten las mismas covariables actuales.

Cuándo puede ser razonable

  • Estados bien definidos.
  • Proceso con memoria limitada.
  • Duración en estado poco relevante.
  • Trayectoria previa poco informativa.
  • Observaciones frecuentes.
  • Modelo parsimonioso.

Cuándo puede fallar

  • Importa cuánto tiempo lleva en el estado.
  • Importa el estado previo.
  • Hay recaídas repetidas.
  • Existe daño acumulado.
  • La historia clínica condiciona el futuro.
  • La reversión tiene significado distinto a la progresión.

Modelo Markov homogéneo

Las intensidades son constantes en el tiempo:

\[ q_{rs}(t) = q_{rs} \]

La matriz generadora es fija:

\[ Q(t) = Q \]

Ejemplo

Q = np.array(
    [
        [

            0.04,

            0.02,
            -0.03,
            0.01

        [
            0.00,
            0.00,
            0.00,
            0.00

np.allclose(

Exponencial matricial

En un modelo homogéneo:

\[ P(t) = \exp(Qt) \]

Tiempo esperado en estado

En un modelo homogéneo, el tiempo medio antes de salir del estado (r) es:

\[ E(T_r) = \frac{ 1 }{ -q_{rr} } \]

Ejemplo

expected_time_s1 = (
    1
    /
    (
        -
        Q[
            1,
            1
        ]
    )
)

Probabilidad del siguiente destino

Condicionado a abandonar (r):

\[ P( r \rightarrow s \mid \text{salida de }r ) = \frac{ q_{rs} }{ -q_{rr} } \]

Ejemplo desde S1

    /

        -

prob_next_s2 = (

        2
    ]

Tiempo de absorción

Cuando existe un estado absorbente, puede estudiarse el tiempo esperado hasta alcanzarlo.

Submatriz transitoria

Q_transient = Q[
    :3,
    :3
]

Matriz fundamental continua

\[ N = (-Q_T)^{-1} \]

N = np.linalg.inv(
    -
    Q_transient
)

Tiempo esperado hasta absorción

expected_time_to_absorption = (
    N
    @
    np.ones(
        Q_transient.shape[
            0
        ]

Interpretación

expected_time_to_absorption[
    0

es el tiempo esperado hasta S3 partiendo de S0, bajo el modelo asumido.

Intensidades con covariables

Para una transición:

\[ q_{rs}(t\mid X) = q_{rs,0}(t) \exp( \beta_{rs}^{\top}X ) \]

Efecto específico

La edad puede tener:

beta distinto para S0 → S1
beta distinto para S1 → S2

Matriz individual

def build_patient_q(
    age,
    dose
):

    q01 = (
        0.05
        *
        np.exp(
            0.02
            *
            age
        )
    )

    q02 = (
        0.01
        *
        np.exp(
            0.01
            *
            dose
        )
    )

    q10 = 0.03
    q12 = 0.04
    q21 = 0.02
    q23 = 0.01

    patient_q = np.array(
        [
            [
                0.0,
                q01,
                q02,
                0.0
            ],
            [
                q10,
                0.0,
                q12,
                0.0
            ],
            [
                0.0,
                q21,
                0.0,
                q23
            ],
            [
                0.0,
                0.0,
                0.0,
                0.0
            ]
        ]
    )

    for row_index in range(
        patient_q.shape[
            0
        ]
    ):

        patient_q[
            row_index,
            row_index
        ] = (
            -
            patient_q[
                row_index,
                :
            ].sum()
        )

    return patient_q

Supuesto Markov y tiempo en estado

El modelo Markov no incorpora de forma natural cuánto tiempo lleva el paciente en el estado.

Ejemplo:

Paciente en S1 desde ayer

Paciente en S1 desde hace un año

Bajo Markov puro pueden tener el mismo riesgo futuro.

Evaluar plausibilidad

Preguntas:

  • ¿La duración en estado cambia el riesgo?
  • ¿Importa el estado anterior?
  • ¿Importa el número de recaídas?
  • ¿La recuperación tiene memoria?
  • ¿Existe daño acumulado?

Test clínico informal

Comparar el riesgo de transición entre:

S1 reciente
vs
S1 prolongado

Si difiere claramente, puede ser preferible un modelo semi-Markov.

Añadir duración como covariable

Una aproximación es incluir tiempo desde entrada en estado.

interval_data[
    "time_since_state_entry"

    interval_data[
        "start"
    ]
    -
    interval_data[
        "state_entry_time"
    ]

Esto rompe la forma Markov pura y aproxima una estructura semi-Markov.

Panel data

En observaciones por visitas:

S0 en día 0
S2 en día 100

el proceso intermedio no se observa.

Un modelo Markov de panel puede integrar sobre posibles trayectorias ocultas.

Matriz de transición entre visitas

Para un intervalo (t):

\[ P(\Delta t) = \exp( Q\Delta t ) \]

La contribución a la verosimilitud depende de:

P_estado inicial, estado final(Δt)

Ejemplo

delta_t = 100

P_delta = expm(
    Q
    *
    delta_t
)

likelihood_contribution = (
    P_delta[
        0,
        2
    ]
)

Verosimilitud de panel

Para observaciones sucesivas:

\[ L = \prod_i P_{x_i,x_{i+1}} ( t_{i+1}-t_i ) \]

Log-verosimilitud

log_likelihood = 0.0

for patient_id, patient in visits.groupby(
    "patient_id"
):

    patient = patient.sort_values(
        "time"
    )

    for index in range(
        len(
            patient
        )
        -
        1
    ):

        origin = patient.iloc[
            index
        ][
            "state_index"
        ]

        destination = patient.iloc[
            index
            +
            1
        ][
            "state_index"
        ]

        delta = (
            patient.iloc[
                index
                +
                1
            ][
                "time"
            ]
            -
            patient.iloc[
                index
            ][
                "time"
            ]

        P_delta = expm(
            Q
            *
            delta

            origin,
            destination

Puede estimarse maximizando la log-verosimilitud.

Los elementos fuera de diagonal deben ser positivos.

Puede parametrizarse:

\[ q_{rs} = \exp( \theta_{rs} ) \]

Simulación de trayectorias

Un modelo Markov permite simular.

Próximo tiempo de salida

Si el paciente está en (r):

\[ T \sim Exponential( -q_{rr} ) \]

Próximo destino

Se elige con probabilidades:

\[ \frac{ q_{rs} }{ -q_{rr} } \]

Simulador conceptual

def simulate_next_transition(
    current_state,
    Q,
    rng
):

    total_rate = (
        -
        Q[
            current_state,
            current_state
        ]
    )

    if total_rate == 0:

        return (
            np.inf,
            current_state
        )

    waiting_time = rng.exponential(
        scale=(
            1
            /
            total_rate
        )
    )

    destination_probabilities = (
        Q[
            current_state,
            :
        ]
        .copy()
    )

    destination_probabilities[
        current_state
    ] = 0

    destination_probabilities = (
        destination_probabilities
        /
        destination_probabilities.sum()
    )

    next_state = rng.choice(
        len(
            destination_probabilities
        ),
        p=destination_probabilities
    )

    return (
        waiting_time,
        next_state
    )

Simular trayectoria

def simulate_path(
    initial_state,
    Q,
    horizon,
    rng
):

    time = 0.0
    state = initial_state

    path = [
        (
            time,
            state
        )
    ]

    while time < horizon:

        waiting_time, next_state = (
            simulate_next_transition(
                current_state=state,
                Q=Q,
                rng=rng
            )
        )

        if (
            not np.isfinite(
                waiting_time
            )
            or
            time
            +
            waiting_time
            >
            horizon
        ):
            break

        time = (
            time
            +
            waiting_time
        )

        state = next_state

        path.append(
            (
                time,
                state
            )
        )

    return path

Limitaciones clínicas

WarningPrecaución

Un modelo Markov puede ser matemáticamente elegante y clínicamente incorrecto si la historia previa importa.

Aplicación a cardiotoxicidad

Modelo propuesto:

S0 ↔ S1 ↔ S2 → S3

Preguntas clave:

  • ¿El riesgo S1 → S2 depende del tiempo en S1?
  • ¿Una recuperación S2 → S1 es equivalente a un S1 inicial?
  • ¿La dosis acumulada rompe el supuesto de memoria limitada?
  • ¿Las visitas irregulares alteran la estimación?
  • ¿S3 debe ser absorbente?

Posible refinamiento

S1_initial
S1_recovered

Esto conserva memoria mediante estados diferentes.

Coste del refinamiento

  • Más estados.
  • Más parámetros.
  • Menos transiciones por arco.
  • Mayor riesgo de inestabilidad.

Reporting

Debe incluir:

  • Diagrama de estados.
  • Matriz (Q).
  • Unidades de tiempo.
  • Supuesto de homogeneidad.
  • Probabilidades de transición.
  • Ocupación.
  • Tiempo esperado en estado.
  • Diagnóstico de Markov.
  • Incertidumbre.

Ejemplo de redacción

Se ajustó un modelo Markov homogéneo
con S3 como estado absorbente.

Las probabilidades de transición a 12 meses
se obtuvieron mediante la exponencial matricial
de la matriz generadora estimada.

Errores frecuentes

  • Confundir Markov con cadena discreta sin considerar tiempo.
  • Interpretar (Q) como matriz de probabilidades.
  • No validar que las filas de (Q) sumen 0.
  • No validar que las filas de (P) sumen 1.
  • Ignorar duración en estado.
  • Asumir homogeneidad sin comprobarla.
  • Usar intervalos muy largos sin reconocer trayectorias ocultas.
  • Estimar desde cero sin control numérico.
  • No comparar con Aalen-Johansen.
  • No validar externamente.
  • Sobredividir estados.
  • Ignorar incertidumbre.

Flujo recomendado

  1. Definir estados.
