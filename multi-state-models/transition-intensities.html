Intensidades y matriz de transición

TipResumen en 30 segundos

Las intensidades de transición describen la tasa instantánea de pasar de un estado a otro.

Para una transición (r s):

\[ q_{rs}(t) \]

representa la intensidad instantánea de cambio, condicionado a encontrarse en el estado (r).

Las intensidades se organizan en una matriz generadora y permiten obtener probabilidades de transición y ocupación.

¿Qué es una intensidad de transición?

Para dos estados (r) y (s):

\[ q_{rs}(t) = \lim_{\Delta t \to 0} \frac{ P[ X(t+\Delta t)=s \mid X(t)=r ] }{ \Delta t } \]

Describe la tasa instantánea de pasar de (r) a (s).

NoteIdea clave

La intensidad no es una probabilidad, aunque permite construir probabilidades de transición.

Ejemplo

q₀₁(t)

representa la intensidad de transición:

S0 → S1

Interpretación clínica

Una intensidad alta significa que, entre los pacientes actualmente en el estado de origen, la transición ocurre con mayor rapidez.

Intensidad frente a probabilidad

Intensidad
→ tasa instantánea

Probabilidad
→ posibilidad acumulada durante un intervalo

Ejemplo conceptual

q₀₁ = 0.02 por mes

No significa exactamente una probabilidad mensual del 2 %, aunque para intervalos muy pequeños puede aproximarse.

Matriz generadora

Las intensidades se organizan en una matriz (Q(t)).

\[ Q(t) = \begin{pmatrix} q_{00}(t) & q_{01}(t) & q_{02}(t) \\ q_{10}(t) & q_{11}(t) & q_{12}(t) \\ q_{20}(t) & q_{21}(t) & q_{22}(t) \end{pmatrix} \]

Elementos fuera de la diagonal

q_rs
→ intensidad de r a s

Elementos diagonales

\[ q_{rr}(t) = - \sum_{s \neq r} q_{rs}(t) \]

Por qué son negativos

La diagonal representa la tasa total de salida del estado.

Ejemplo con cuatro estados

S0 ↔ S1 ↔ S2 → S3

Una posible matriz:

\[ Q = \begin{pmatrix} -(q_{01}+q_{02}) & q_{01} & q_{02} & 0 \\ q_{10} & -(q_{10}+q_{12}) & q_{12} & 0 \\ 0 & q_{21} & -(q_{21}+q_{23}) & q_{23} \\ 0 & 0 & 0 & 0 \end{pmatrix} \]

Estado absorbente

Para un estado absorbente:

S3

todas las intensidades de salida son 0.

Fila de S3
→ todos los valores 0

Matriz en Python

import numpy as np

q01 = 0.05
q02 = 0.01
q10 = 0.03
q12 = 0.04
q21 = 0.02
q23 = 0.01
Q = np.array(
    [
        [
            -(q01 + q02),
            q01,
            q02,
            0.0
        ],
        [
            q10,
            -(q10 + q12),
            q12,
            0.0
        ],
        [
            0.0,
            q21,
            -(q21 + q23),
            q23
        ],
        [
            0.0,
            0.0,
            0.0,
            0.0
        ]
    ]
)

Validar filas

Cada fila debe sumar aproximadamente 0.

Q.sum(
    axis=1
)

Intensidad total de salida

Desde un estado (r):

\[ q_r(t) = \sum_{s \neq r} q_{rs}(t) \]

Ejemplo desde S1

S1 → S0
S1 → S2

Entonces:

\[ q_1(t) = q_{10}(t) + q_{12}(t) \]

Tiempo de permanencia

En un modelo Markov homogéneo, el tiempo de permanencia en un estado sigue una distribución exponencial con tasa igual a la intensidad total de salida.

\[ T_r \sim Exponential( q_r ) \]

Esperanza del tiempo en estado

\[ E(T_r) = \frac{1}{q_r} \]

Ejemplo

q1 = (
    q10
    +
    q12
)

expected_time_s1 = (
    1
    /
    q1
)

Probabilidad del siguiente destino

Condicionado a abandonar el estado (r):

\[ P( r \rightarrow s \mid \text{salida de }r ) = \frac{ q_{rs} }{ \sum_{k \neq r} q_{rk} } \]

Ejemplo desde S1

prob_next_s0 = (
    q10
    /
    (
        q10
        +
        q12
    )
)

prob_next_s2 = (
    q12
    /
    (
        q10
        +
        q12
    )
)

Diferencia importante

La intensidad total determina cuánto se tarda en salir.

Las proporciones relativas determinan hacia qué estado se sale.

Estimación no paramétrica simple

En un modelo homogéneo sin covariables, una estimación intuitiva es:

\[ \hat{q}_{rs} = \frac{ N_{rs} }{ Y_r } \]

donde:

  • (N_{rs}): número de transiciones (r s).
  • (Y_r): tiempo total en riesgo en (r).

Calcular tiempo en riesgo

interval_data[
    "duration"
] = (
    interval_data[
        "stop"
    ]
    -
    interval_data[
        "start"
    ]
)
time_at_risk = (
    interval_data
    .groupby(
        "from_state"
    )[
        "duration"
    ]
    .sum()
)

Contar transiciones

transition_counts = (
    interval_data
    .loc[
        interval_data[
            "status"
        ]
        ==
        1
    ]
    .groupby(
        [
            "from_state",
            "to_state"
        ]

Estimar intensidad bruta

rows = []

for (
    origin,
    destination
), count in transition_counts.items():

    rate = (
        count
        /
        time_at_risk[
            origin
        ]
    )

    rows.append(
        {
            "from_state": origin,
            "to_state": destination,
            "transitions": count,
            "time_at_risk": time_at_risk[
                origin
            ],
            "intensity": rate
        }
    )
intensity_table = pd.DataFrame(
    rows
)

intensidad

Intervalos de confianza aproximados

Para tasas basadas en recuentos Poisson puede utilizarse una aproximación.

intensity_table[
    "se"

            "transitions"

    ]

Precaución

Con pocos eventos, las aproximaciones normales pueden ser pobres.

Intensidades dependientes del tiempo

En muchos procesos:

q_rs(t)

cambia con el tiempo.

Ejemplos:

  • Mayor progresión al inicio.
  • Recuperación tardía.
  • Efecto acumulativo de tratamiento.
  • Cambios de protocolo.

Cox específico por transición

Para una transición (r s):

\[ q_{rs}(t \mid X) = q_{rs,0}(t) \exp( \beta_{rs}^{\top}X ) \]

Interpretación

exp(beta_rs)
→ hazard ratio específico de esa transición

Dataset específico

transition_12 = expanded_data.loc[
    expanded_data[
        "transition_id"
    ]
    ==
    4
].copy()

Ajustar Cox

from lifelines import CoxPHFitter

cph_12 = CoxPHFitter()

cph_12.fit(
    transition_12[
        [
            "start",
            "stop",
            "event",
            "age",
            "baseline_lvef",
            "cumulative_dose"
        ]

    duration_col="stop",
    event_col="event",
    entry_col="start"
)

Interpretación clínica

Un HR de 1.30 para dosis acumulada en S1 → S2 indica un hazard específico de progresión aproximadamente 30 % mayor por unidad definida de dosis.

Probabilidades de transición

A partir de (Q), en un modelo homogéneo:

\[ P(t) = \exp( Qt ) \]

donde () es la exponencial matricial.

Calcular en Python

from scipy.linalg import expm

P_12_months = expm(
    Q
    *
    12
)

Interpretación

P_12_months[
    0,
    2
]

es la probabilidad de estar en S2 a los 12 meses, comenzando en S0.

Validar matriz P

Cada fila debe sumar aproximadamente 1.

P_12_months.sum(
    axis=1
)

Matriz de probabilidades

probability_matrix = pd.DataFrame(

        "S1",

        "S3"
    ],
    columns=[
        "S0",
        "S1",
        "S2",
        "S3"
    ]
)

Horizonte variable

times = [
    1,

Modelo no homogéneo

Si (Q) cambia con el tiempo:

P(u,t)

no se obtiene simplemente con:

exp(Q × tiempo)

Puede requerirse:

  • Product integral.
  • Aalen-Johansen.
  • Integración numérica.
  • Piecewise constant intensities.

Matrices por periodos

Q_early = Q.copy()

Q_late = Q.copy()
P_0_6 = expm(
    Q_early
    *
    6
)

P_6_12 = expm(
    Q_late
    *
    6
)

P_0_12 = (
    P_0_6
    @
    P_6_12
)

Product integral

Para intensidades variables:

\[ P(u,t) = \prod_{(u,t]} [ I+dA(v) ] \]

Aalen-Johansen es el estimador no paramétrico habitual de esta cantidad.

Intensidad acumulada

\[ A_{rs}(t) = \int_0^t q_{rs}(u)\,du \]

Nelson-Aalen por transición

Puede estimarse una intensidad acumulada específica por transición.

Estimación conceptual

from lifelines import NelsonAalenFitter

naf = NelsonAalenFitter()

Para cada estado de origen, las otras salidas deben considerarse competing transitions.

Censura de salidas competidoras

Al modelar S1 → S2:

S1 → S0

se trata como salida competidora en el análisis cause-specific.

Riesgo específico

Solo contribuyen al risk set quienes están actualmente en el estado de origen.

Error frecuente

Incluir a todos los pacientes desde tiempo cero en cada transición, aunque todavía no hayan entrado en el estado de origen.

Entrada al risk set

Para S1 → S2:

Entrada
→ momento en que el paciente llega a S1

Salida del risk set

  • Transición a S2.
  • Transición a otro estado.
  • Censura.
  • Estado terminal.

Clock-forward y clock-reset

Clock-forward

start y stop
→ tiempo desde origen global

Clock-reset

start = 0
stop = tiempo en estado

Implicaciones

Clock-forward modela el efecto del tiempo global.

Clock-reset modela el efecto del tiempo desde entrada al estado.

Markov frente a semi-Markov

Markov

La intensidad depende del estado actual y del tiempo global.

Semi-Markov

Puede depender de cuánto tiempo lleva el paciente en el estado.

expanded_data[

presenta S2 → S3

Puede generar coeficientes extremos.

Soluciones

  • Fusionar categorías.
  • Efectos compartidos.
  • Modelo bayesiano.
  • Más datos.
  • Simplificar transición.

Intensidad específica por centro

Puede incluirse:

  • Centro como covariable.
  • Estratificación.
  • Frailty.
  • Efectos aleatorios.

Heterogeneidad no observada

Dos pacientes en el mismo estado pueden tener distinta propensión a progresar.

Los modelos de frailty pueden capturar parte de esa heterogeneidad.

Predicción individual

Para un perfil (X):

Q(X)

contiene intensidades ajustadas.

A partir de ella pueden calcularse:

  • Probabilidades de transición.
  • Ocupación.
  • Tiempo esperado.
  • Riesgo de estado absorbente.

Matriz individual

Conceptualmente:

Q_patient = Q_baseline.copy()

La diagonal debe recalcularse después.

Recalcular diagonal

for row_index in range(
    Q_patient.shape[
        0
    ]
):

    off_diagonal_sum = (
        Q_patient[
            row_index,
            :
        ].sum()
        -
        Q_patient[
            row_index,
            row_index
        ]
    )

    Q_patient[
        row_index,
        row_index
    ] = (
        -
        off_diagonal_sum
    )

NoteAplicación clínica

Las intensidades permiten distinguir entre:

  • Salir rápidamente de un estado.
  • Permanecer mucho tiempo.
  • Progresar.
  • Recuperarse.

Errores frecuentes

  • Interpretar intensidad como probabilidad.
  • No recalcular la diagonal.
  • Incluir pacientes fuera del estado de origen.
  • Ignorar transiciones competidoras.
  • Usar covariables futuras.
  • Ajustar demasiados modelos con pocos eventos.
  • Mezclar clock-forward y clock-reset.
  • No declarar unidades.
  • No comprobar filas de (Q).
  • Extrapolar con intensidades constantes sin justificar.
  • No estimar incertidumbre.
  • Confundir probabilidad de siguiente destino con probabilidad a tiempo fijo.

Flujo recomendado

  1. Definir arcos.
  2. Calcular tiempo en riesgo.
  3. Contar transiciones.
  4. Estimar intensidades brutas.
  5. Construir matriz (Q).
  6. Ajustar modelos por transición.
  7. Incorporar covariables.
  8. Revisar transiciones escasas.
  9. Calcular probabilidades.
  10. Calcular ocupación.
  11. Estimar incertidumbre.
  12. Comunicar resultados.
