Workflow multiestado para cardiotoxicidad

TipResumen en 30 segundos

Este workflow aplica los modelos multiestado a la evolución de la cardiotoxicidad pediátrica:

S0
→ estado cardiovascular normal

S1
→ cardiotoxicidad leve

S2
→ cardiotoxicidad moderada

S3
→ cardiotoxicidad grave

El objetivo es transformar valoraciones cardiovasculares longitudinales en trayectorias clínicas y modelar:

  • Transiciones entre estados.
  • Tiempo hasta la siguiente transición.
  • Recuperación y progresión.
  • Probabilidad de ocupar cada estado.
  • Riesgo individual de alcanzar S2 o S3.

Pregunta clínica

Una formulación general:

En pacientes pediátricos oncológicos,
¿qué factores se asocian con las transiciones
entre estados de cardiotoxicidad
y cuánto tiempo transcurre hasta cada cambio?

Pregunta predictiva

Dado el estado cardiovascular actual
y la información clínica disponible,
¿cuál es la probabilidad de que el paciente
progrese, permanezca estable o se recupere
durante los próximos 6, 12 y 24 meses?
NoteIdea clave

El objetivo no es predecir únicamente cardiotoxicidad sí/no, sino reconstruir y anticipar la trayectoria clínica completa.

Definición de estados

S0. Normal

Criterio conceptual:

FEVI ≥ 50 %
y
sin descenso relativo de GLS ≥ 15 %
respecto al baseline
y
sin biomarcadores alterados

S1. Leve

Criterio conceptual:

FEVI ≥ 50 %
y al menos uno:
- descenso relativo de GLS ≥ 15 %
- troponina alterada
- NT-proBNP alterado

S2. Moderada

Criterio conceptual:

FEVI 40–49 %
con una caída clínicamente relevante
respecto al baseline
o acompañada de alteración de GLS
o biomarcadores

S3. Grave

FEVI < 40 %

Estado terminal opcional

Puede añadirse:

D
→ fallecimiento

como estado absorbente.

Tiempo cero

La opción principal:

Inicio del tratamiento oncológico

Alternativas:

  • Diagnóstico.
  • Primera exposición a antraciclinas.
  • Primera valoración cardiovascular.
  • Inicio del seguimiento prospectivo.

Recomendación

Usar una definición única y clínicamente reproducible.

Estado basal

Para cada paciente:

Primera valoración cardiovascular
alrededor del tiempo cero

Debe definirse una ventana.

Ejemplo:

-30 a +14 días
respecto al inicio del tratamiento

Elección de baseline

Si existen varias valoraciones:

  • La más cercana a tiempo cero.
  • Priorizar antes del tratamiento.
  • Exigir calidad mínima.
  • Documentar la regla.

GLS basal

El descenso relativo se calcula respecto al valor basal.

\[ \text{descenso relativo GLS} = \frac{ |GLS_{baseline}| - |GLS_t| }{ |GLS_{baseline}| } \]

Ejemplo

GLS basal = -20 %
GLS actual = -16 %

Descenso relativo:
(20 - 16) / 20 = 0.20
→ 20 %

Implementación

def gls_relative_drop(
    baseline_gls,
    current_gls
):

    if (
        pd.isna(
            baseline_gls
        )
        or
        pd.isna(
            current_gls
        )
        or
        baseline_gls
        ==
        0
    ):
        return pd.NA

    return (
        abs(
            baseline_gls
        )
        -
        abs(
            current_gls
        )
    ) / abs(
        baseline_gls
    )

def choose_lvef(
    lvef_simpson,
    lvef_mmode
):

    if pd.notna(
        lvef_simpson
    ):
        return lvef_simpson

    if pd.notna(
        lvef_mmode
    ):
        return lvef_mmode

    return pd.NA

Biomarcadores alterados

Ejemplo de umbrales del proyecto:

Troponina I > 0.02

NT-proBNP > 150

Implementación

def biomarker_flags(
    troponin_i,
    ntprobnp
):

    troponin_high = (
        pd.notna(
            troponin_i
        )
        and
        troponin_i
        >
        0.02
    )

    ntprobnp_high = (
        pd.notna(
            ntprobnp
        )
        and
        ntprobnp
        >
        150
    )

    return (
        troponin_high,
        ntprobnp_high
    )

Clasificador de estado

def classify_cardiotoxicity_state(
    lvef,
    baseline_lvef,
    gls_drop,
    troponin_high,
    ntprobnp_high
):

    biomarker_high = (
        troponin_high
        or
        ntprobnp_high
    )

    if pd.notna(
        lvef
    ) and lvef < 40:
        return "S3"

    if pd.notna(
        lvef
    ) and 40 <= lvef < 50:

        lvef_drop = (
            baseline_lvef
            -
            lvef
            if pd.notna(
                baseline_lvef
            )
            else pd.NA
        )

        if (
            pd.notna(
                lvef_drop
            )
            and
            lvef_drop
            >
            10
        ):
            return "S2"

        if (
            pd.notna(
                gls_drop
            )
            and
            gls_drop
            >=
            0.15
        ):
            return "S2"

        if biomarker_high:
            return "S2"

        return "S2"

    if pd.notna(
        lvef
    ) and lvef >= 50:

        if (
            (
                pd.notna(
                    gls_drop
                )
                and
                gls_drop
                >=
                0.15
            )
            or
            biomarker_high
        ):
            return "S1"

        return "S0"

    return pd.NA

Importante

La función debe reflejar exactamente la definición clínica validada.

No debe modificarse durante el análisis sin:

  • Nueva versión.
  • Nueva clasificación.
  • Análisis de sensibilidad.

def first_non_null(
    series
):

    non_null = series.dropna()

    if non_null.empty:
        return pd.NA

    return non_null.iloc[

from lifelines import CoxPHFitter

transition_models = {}

for transition_id in sorted(
    expanded_data[
        "transition_id"
    ]
    .unique()
):

    transition_df = expanded_data.loc[
        expanded_data[
            "transition_id"
        ]
        ==
        transition_id
    ].copy()

    model = CoxPHFitter(
        penalizer=0.05
    )

    model.fit(
        transition_df[
            [
                "start",
                "stop",
                "event",
                "age_at_treatment",
                "baseline_lvef",
                "cumulative_anthracycline"
            ]
        ],
        duration_col="stop",
        event_col="event",
        entry_col="start"
    )

    transition_models[
        transition_id
    ] = model

P(S2 o S3 en 6 meses) ≥ 30 %

Errores frecuentes

  • Modificar estados después de ver resultados.
  • Usar missing como normal.
  • Mezclar FEVI sin prioridad.
  • Calcular GLS sin baseline.
  • Usar dosis futura.
  • Ignorar ventanas analíticas.
  • No añadir intervalo censurado.
  • No revisar saltos.
  • Comparar centros sin revisar frecuencia de visitas.
  • Ajustar demasiados parámetros.
  • Evaluar solo C-index.
  • Desplegar sin shadow mode.
