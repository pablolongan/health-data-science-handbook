Predicción y evaluación en modelos multiestado

TipResumen en 30 segundos

La evaluación de un modelo multiestado debe ir más allá de un único C-index.

Debe comprobar:

  • Probabilidades de transición.
  • Probabilidades de ocupación.
  • Riesgo de alcanzar estados concretos.
  • Tiempo esperado en cada estado.
  • Calibración por horizonte.
  • Discriminación por transición.
  • Predicción dinámica.
  • Validación temporal y externa.

¿Qué puede predecir un modelo multiestado?

Un modelo multiestado puede responder preguntas como:

¿En qué estado estará el paciente
dentro de 6 meses?
¿Cuál es la probabilidad
de progresar de S1 a S2?
¿Cuál es la probabilidad
de alcanzar S3 antes de 2 años?
¿Cuánto tiempo se espera
que permanezca en S1?
NoteIdea clave

La métrica debe corresponder exactamente a la pregunta clínica.

Tipos de predicción

1. Probabilidad de transición

\[ P_{rs}(u,t) = P[ X(t)=s \mid X(u)=r ] \]

2. Probabilidad de ocupación

\[ P[ X(t)=s ] \]

3. First-passage probability

Probabilidad de alcanzar por primera vez un estado antes de un horizonte.

4. Tiempo esperado en estado

\[ E[ T_s(0,\tau) ] = \int_0^\tau P[ X(t)=s ]dt \]

5. Predicción del siguiente estado

Desde S1:
P(S0 próximo) = ...
P(S2 próximo) = ...

6. Predicción dinámica

La predicción se actualiza cuando llegan nuevos datos.

Baseline
→ predicción inicial

Nueva ecocardiografía
→ actualización

Nuevo biomarcador
→ nueva actualización

Estado actual como condición inicial

Si el paciente está en S1 en el tiempo (u):

current_state_distribution = {
    "S0": 0.0,
    "S1": 1.0,
    "S2": 0.0,
    "S3": 0.0
}

Estado incierto

En un HMM:

current_state_distribution = {
    "S0": 0.10,
    "S1": 0.65,
    "S2": 0.24,
    "S3": 0.01

La predicción debe propagar toda la distribución, no solo el estado más probable.

Matriz individual

Cada paciente puede tener una matriz:

  • Edad.

Ejemplo conceptual

def build_patient_q(
    age,
    cumulative_dose,
    lvef
):

    q01 = (
        0.02
        *
        np.exp(
            0.01
            *
            age
        )
    )

    q12 = (
        0.03
        *
        np.exp(
            0.20
            *
            cumulative_dose
            -
            0.05
            *
            lvef
        )
    )

    q10 = 0.04
    q21 = 0.02
    q23 = 0.01

    Q = np.array(
        [
            [
                -q01,
                q01,
                0.00,
                0.00
            ],
            [
                q10,
                -(q10 + q12),
                q12,
                0.00
            ],
            [
                0.00,
                q21,
                -(q21 + q23),
                q23
            ],
            [
                0.00,
                0.00,
                0.00,
                0.00
            ]
        ]
    )

    return Q

Un C-index por transición:

  • No evalúa ocupación.
  • No mide calibración.
  • No resume el proceso completo.
  • Puede ser inestable con pocos eventos.

Brier score por transición

Evalúa error de probabilidad para:

Transición concreta antes de t

Debe manejar correctamente:

  • Censura.
  • Salidas competidoras.
  • Entrada al estado.

Brier multiestado

Una extensión evalúa la diferencia entre:

  • Vector de probabilidades predichas.
  • Estado observado.

Fórmula conceptual

\[ BS(t) = \frac{1}{n} \sum_i \sum_s [ I( X_i(t)=s ) - \hat{P}_{is}(t) ]^2 \]

Ejemplo simple sin censura

def multistate_brier_score(
    observed_states,
    predicted_probabilities,
    state_names
):

    state_to_index = {
        state:
        index
        for index, state
        in enumerate(
            state_names
        )
    }

    one_hot = np.zeros_like(
        predicted_probabilities
    )

    for row_index, state in enumerate(
        observed_states
    ):

        one_hot[
            row_index,
            state_to_index[
                state
            ]
        ] = 1.0

    squared_error = (
        one_hot
        -
        predicted_probabilities
    ) ** 2

    return squared_error.sum(
        axis=1
    ).mean()

Precaución

Con censura se necesita:

  • IPCW.
  • Pseudo-observations.
  • Métodos específicos multiestado.

El ejemplo anterior es solo didáctico.

Integrated Brier Score multiestado

Integra el error a lo largo del tiempo.

\[ IBS = \frac{1}{\tau_2-\tau_1} \int_{\tau_1}^{\tau_2} BS(t)dt \]

Errores frecuentes

  • Evaluar solo C-index.
  • Confundir ocupación y first-passage.
  • Evaluar fuera del risk set.
  • Ignorar censura.
  • Usar proporciones brutas.
  • Mezclar pacientes entre train y test.
  • Usar smoothing para predicción online.
  • No evaluar por estado inicial.
  • No reportar horizontes.
  • Ignorar transiciones raras.
  • No evaluar calibración.
  • Elegir el modelo solo por discriminación.

Flujo recomendado

  1. Definir pregunta predictiva.
  2. Definir estado inicial.
  3. Elegir horizonte.
  4. Generar probabilidades.
  5. Evaluar discriminación.
  6. Evaluar Brier.
  7. Evaluar calibración.
  8. Evaluar first-passage.
  9. Analizar alertas.
  10. Aplicar bootstrap.
  11. Validar temporalmente.
  12. Validar externamente.
