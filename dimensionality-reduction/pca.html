Principal Component Analysis (PCA)

TipResumen en 30 segundos

PCA es una técnica de reducción de dimensionalidad que transforma varias variables numéricas correlacionadas en un conjunto menor de componentes no correlacionados.

Cada componente es una combinación lineal de las variables originales y se ordena según la cantidad de varianza que explica.

¿Qué problema resuelve?

En muchos datasets existen numerosas variables que contienen información parcialmente redundante.

Por ejemplo, en un dataset clínico pueden existir medidas relacionadas entre sí:

  • Peso.
  • Altura.
  • Índice de masa corporal.
  • Superficie corporal.
  • Perímetros corporales.

Estas variables no son idénticas, pero pueden estar correlacionadas. PCA intenta resumir parte de esa información en un número menor de componentes.

PCA puede utilizarse para:

  • Reducir el número de variables.
  • Visualizar datasets de alta dimensionalidad.
  • Detectar patrones.
  • Mitigar problemas de multicolinealidad.
  • Crear variables de entrada para otros modelos.
NoteIdea clave

PCA no selecciona variables originales. Crea variables nuevas llamadas componentes principales.

Intuición

Imagina una nube de puntos formada por dos variables correlacionadas.

Aunque el dataset tenga dos ejes originales, la mayor parte de la variabilidad puede concentrarse en una dirección diagonal.

PCA encuentra esa dirección y la convierte en el primer componente principal.

El segundo componente se coloca perpendicularmente al primero y captura la variabilidad restante.

De este modo, PCA cambia el sistema de coordenadas original por uno nuevo que intenta representar los datos de forma más eficiente.

Fundamentos teóricos

Componentes principales

Cada componente principal es una combinación lineal de las variables originales.

Para un dataset con variables \(x_1, x_2, \ldots, x_p\), el primer componente puede expresarse como:

\[ PC_1 = w_{11}x_1 + w_{12}x_2 + \cdots + w_{1p}x_p \]

El segundo componente se expresa como:

\[ PC_2 = w_{21}x_1 + w_{22}x_2 + \cdots + w_{2p}x_p \]

Los coeficientes \(w\) se denominan pesos o loadings.

Varianza explicada

Cada componente explica una parte de la varianza total del dataset.

La proporción de varianza explicada por el componente \(j\) puede expresarse como:

\[ \text{Explained variance ratio}_j = \frac{\lambda_j} {\sum_{k=1}^{p}\lambda_k} \]

donde \(\lambda_j\) es el autovalor asociado al componente \(j\).

Varianza explicada acumulada

La varianza explicada acumulada indica cuánta información se conserva utilizando los primeros componentes.

Por ejemplo:

  • 1 componente: 45 %.
  • 2 componentes: 68 %.
  • 3 componentes: 82 %.
  • 4 componentes: 91 %.

En este caso, seleccionar cuatro componentes conservaría aproximadamente el 91 % de la varianza total.

WarningImportante

Un componente que explica mucha varianza no tiene por qué ser el componente más útil para predecir un desenlace clínico.

¿Por qué es importante escalar?

PCA está influido por la escala de las variables.

Imagina estas variables:

  • Edad, medida en años.
  • Troponina, medida con valores pequeños.
  • Presión arterial, medida en mmHg.

Una variable con valores numéricamente mayores puede dominar el análisis aunque no sea clínicamente más importante.

Por eso, antes de aplicar PCA suele utilizarse:

StandardScaler()

El escalado transforma cada variable para que tenga aproximadamente:

  • Media igual a 0.
  • Desviación estándar igual a 1.
ImportantRegla práctica

Si las variables están medidas en escalas o unidades diferentes, escala antes de aplicar PCA.

Supuestos y condiciones

PCA funciona mejor cuando:

  • Las variables son numéricas.
  • Existen relaciones aproximadamente lineales.
  • Las variables contienen varianza informativa.
  • Hay correlación entre algunas variables.
  • Los valores extremos han sido revisados.
  • Las escalas se han tratado adecuadamente.

Cuándo utilizar PCA

PCA puede ser adecuado cuando:

  • Tienes muchas variables numéricas correlacionadas.
  • Quieres reducir el número de variables.
  • Quieres visualizar observaciones en dos o tres dimensiones.
  • Quieres reducir multicolinealidad.
  • Quieres comprimir información antes de otro modelo.
  • Quieres explorar patrones latentes.

Cuándo no utilizar PCA

PCA puede no ser adecuado cuando:

  • Necesitas interpretar directamente cada variable original.
  • Las relaciones entre variables son principalmente no lineales.
  • La mayoría de las variables son categóricas.
  • Tienes muy pocas variables.
  • Los componentes son difíciles de justificar clínicamente.
  • El objetivo es seleccionar variables originales, no transformarlas.

Flujo de trabajo recomendado

  1. Seleccionar únicamente variables numéricas relevantes.
  2. Revisar valores ausentes.
  3. Revisar valores extremos.
  4. Separar entrenamiento y prueba si PCA forma parte de un modelo predictivo.
  5. Imputar valores ausentes utilizando solo entrenamiento.
  6. Escalar las variables utilizando solo entrenamiento.
  7. Ajustar PCA utilizando solo entrenamiento.
  8. Elegir el número de componentes.
  9. Transformar entrenamiento y prueba.
  10. Interpretar la varianza explicada y los loadings.
  11. Evaluar el impacto en el modelo posterior.

Código mínimo

from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X_scaled = StandardScaler().fit_transform(X)

pca = PCA(n_components=2)

X_pca = pca.fit_transform(X_scaled)

print(pca.explained_variance_ratio_)

Seleccionar componentes según varianza explicada

from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X_scaled = StandardScaler().fit_transform(X)

pca = PCA(n_components=0.95)

X_pca = pca.fit_transform(X_scaled)

print(f"Número de componentes: {pca.n_components_}")
print(
    "Varianza explicada acumulada:",
    pca.explained_variance_ratio_.sum()
)

Implementación segura dentro de un pipeline

from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression

pipeline = Pipeline(
    steps=[
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler()),
        ("pca", PCA(n_components=0.95)),
        (
            "model",
            LogisticRegression(
                max_iter=1000,
                random_state=42
            )
        )
    ]
)

pipeline.fit(X_train, y_train)

y_pred = pipeline.predict(X_test)
CautionError frecuente: data leakage

No ajustes el imputador, el escalador ni PCA con todo el dataset antes de separar entrenamiento y prueba.

El pipeline ayuda a evitar que la información del conjunto de prueba influya en el entrenamiento.

Inspeccionar la varianza explicada

import pandas as pd

explained_variance = pd.DataFrame(
    {
        "component": range(
            1,
            len(pca.explained_variance_ratio_) + 1
        ),
        "explained_variance_ratio":
            pca.explained_variance_ratio_,
        "cumulative_explained_variance":
            pca.explained_variance_ratio_.cumsum()
    }
)

display(explained_variance)

Interpretar los loadings

import pandas as pd

loadings = pd.DataFrame(
    pca.components_.T,
    index=X.columns,
    columns=[
        f"PC{i}"
        for i in range(
            1,
            pca.n_components_ + 1
        )
    ]
)

display(loadings)

Un valor absoluto elevado indica que la variable tiene una contribución importante al componente.

Consideraciones en datos clínicos

NoteAplicación clínica

PCA puede resumir información redundante, pero también puede generar componentes difíciles de interpretar clínicamente.

Mediciones repetidas

Si un paciente aparece varias veces, la separación entre entrenamiento y prueba debería hacerse a nivel de paciente, no a nivel de fila.

Valores ausentes

La ausencia de una prueba puede estar relacionada con:

  • La gravedad.
  • La indicación clínica.
  • El centro.
  • El momento del seguimiento.
  • La disponibilidad de recursos.

Diferencias entre centros

PCA puede capturar diferencias entre centros en lugar de patrones clínicos relevantes si existen diferencias en:

  • Equipos.
  • Unidades.
  • Protocolos.
  • Poblaciones.
  • Métodos de laboratorio.

Errores frecuentes

  • Aplicar PCA antes de separar entrenamiento y prueba.
  • Escalar utilizando todo el dataset.
  • No escalar variables con unidades diferentes.
  • Aplicar PCA directamente a variables categóricas.
  • Interpretar los componentes como variables clínicas reales.
  • Pensar que más varianza explicada siempre implica mejor predicción.
  • Ignorar valores extremos que dominan los componentes.
