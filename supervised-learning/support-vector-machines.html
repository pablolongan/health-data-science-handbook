Support Vector Machines

TipResumen en 30 segundos

Las Support Vector Machines buscan una frontera que separe las clases con el mayor margen posible.

Los puntos más cercanos a la frontera se llaman support vectors.

Con kernels, una SVM puede aprender fronteras no lineales.

Son modelos potentes, pero requieren escalado y un ajuste cuidadoso de hiperparámetros.

¿Qué es una Support Vector Machine?

Una Support Vector Machine, o SVM, es un modelo supervisado que puede utilizarse para:

  • Clasificación.
  • Regresión.
  • Detección de novedades.
  • Problemas lineales y no lineales.

En clasificación, busca una frontera de decisión que separe las clases.

Frontera de decisión

En dos dimensiones, la frontera puede representarse como una línea:

Clase 0  ○ ○ ○    │    ● ● ●  Clase 1
        ○ ○       │      ● ●
                  │
          frontera de decisión

En más dimensiones, la frontera se denomina hiperplano.

Margen

El margen es la distancia entre la frontera y las observaciones más cercanas de cada clase.

Clase 0        margen        Clase 1

○ ○ ○      ┆     │     ┆      ● ● ●
             ┆    │    ┆
                  frontera

La SVM intenta maximizar este margen.

NoteIdea clave

Una frontera con un margen amplio suele generalizar mejor que una frontera que pasa demasiado cerca de las observaciones.

Support vectors

Los support vectors son las observaciones más cercanas a la frontera.

Son especialmente importantes porque determinan la posición del hiperplano.

Las observaciones alejadas de la frontera suelen influir menos en el modelo final.

Clasificación lineal

Una frontera lineal puede escribirse como:

\[ w^\top x + b = 0 \]

donde:

  • \(w\) define la orientación.
  • \(b\) desplaza la frontera.
  • \(x\) representa las variables predictoras.

La clase depende del signo de:

\[ f(x) = w^\top x + b \]

Hard margin

El hard margin exige separar perfectamente todas las observaciones.

Esto solo funciona cuando:

  • Las clases son perfectamente separables.
  • No existe ruido.
  • No hay outliers problemáticos.

En datos reales suele ser demasiado rígido.

Soft margin

El soft margin permite algunos errores a cambio de una frontera más estable.

El parámetro principal es C.

Parámetro C

C controla el equilibrio entre:

  • Maximizar el margen.
  • Penalizar errores de clasificación.
C pequeño
→ margen más amplio
→ mayor regularización
→ más errores tolerados

C grande
→ margen más estrecho
→ menor regularización
→ intenta clasificar mejor train
WarningRiesgo

Un valor de C demasiado alto puede producir overfitting.

LinearSVC

Para clasificación lineal:

from sklearn.svm import LinearSVC

model = LinearSVC(
    C=1.0,
    class_weight=None,
    random_state=42
)

LinearSVC suele ser eficiente cuando:

  • Hay muchas observaciones.
  • Hay muchas variables.
  • La frontera lineal es suficiente.

SVC con kernel lineal

from sklearn.svm import SVC

model = SVC(
    kernel="linear",
    C=1.0,
    class_weight=None,
    random_state=42
)

SVC(kernel="linear") y LinearSVC no son implementaciones idénticas.

Preparar los datos

features = [
    "age",
    "weight",
    "troponin",
    "ntprobnp"
]

target = "cardiotoxicity"

X = df[features]

y = df[target]

Separar train y test

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.20,
    stratify=y,
    random_state=42
)

Escalado

El escalado es esencial en SVM.

Ejemplo de escalas originales:

Edad       → 0 a 18
Peso       → 2 a 100
Troponina  → 0.001 a 0.200
NT-proBNP  → 10 a 5000

Sin escalado, las variables de mayor magnitud pueden dominar las distancias.

Pipeline básico

from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

model = Pipeline(
    steps=[
        (
            "imputer",
            SimpleImputer(
                strategy="median"
            )
        ),
        (
            "scaler",
            StandardScaler()
        ),
        (
            "classifier",
            SVC(
                kernel="linear",
                C=1.0,
                random_state=42
            )
        )
    ]
)

Entrenar el modelo

model.fit(
    X_train,
    y_train
)

Predicción de clases

y_pred = model.predict(
    X_test
)

Decision function

SVC produce una puntuación de decisión:

decision_score = model.decision_function(
    X_test
)

En clasificación binaria:

Score negativo
→ tendencia hacia clase 0

Score positivo
→ tendencia hacia clase 1

La puntuación no es una probabilidad.

Probabilidades calibradas

Para obtener probabilidades puede calibrarse el clasificador.

from sklearn.calibration import CalibratedClassifierCV

base_svc = Pipeline(
    steps=[
        (
            "imputer",
            SimpleImputer(
                strategy="median"
            )
        ),
        (
            "scaler",
            StandardScaler()
        ),
        (
            "classifier",
            SVC(
                kernel="rbf",
                C=1.0,
                gamma="scale",
                class_weight=None,
                random_state=42
            )
        )
    ]
)
calibrated_model = CalibratedClassifierCV(
    estimator=base_svc,
    method="sigmoid",
    cv=5
)

calibrated_model.fit(
    X_train,
    y_train
)

y_probability = calibrated_model.predict_proba(
    X_test
)[:, 1]
NoteBuena práctica

La calibración debe realizarse utilizando únicamente datos de entrenamiento.

Kernel trick

Cuando las clases no pueden separarse con una línea, puede utilizarse un kernel.

El kernel permite trabajar implícitamente en un espacio de mayor dimensión.

Espacio original
→ clases no separables linealmente

Transformación mediante kernel
→ separación posible

Kernel lineal

SVC(
    kernel="linear"
)

Útil cuando:

  • Hay muchas variables.
  • La relación es aproximadamente lineal.
  • Se busca mayor interpretabilidad.
  • Se trabaja con datos de alta dimensión.

Kernel RBF

SVC(
    kernel="rbf"
)

RBF significa Radial Basis Function.

Es una opción habitual para relaciones no lineales.

Puede crear fronteras curvas y complejas.

Kernel polinómico

SVC(
    kernel="poly",
    degree=3
)

Permite modelar relaciones polinómicas.

Suele ser más difícil de ajustar e interpretar.

Kernel sigmoide

SVC(
    kernel="sigmoid"
)

Se utiliza menos en la práctica.

Parámetro gamma

gamma controla el alcance de influencia de cada observación en kernels como RBF.

Gamma pequeño
→ influencia amplia
→ frontera suave

Gamma grande
→ influencia local
→ frontera compleja
WarningRiesgo

Un gamma demasiado alto puede hacer que el modelo memorice train.

Gamma scale

SVC(
    kernel="rbf",
    gamma="scale"
)

Es una opción inicial razonable.

C y gamma conjuntamente

C Gamma Comportamiento probable
Bajo Bajo Modelo muy suave
Alto Bajo Margen estricto, frontera suave
Bajo Alto Regularización fuerte, efectos locales
Alto Alto Frontera muy compleja

Pipeline con variables categóricas

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder

numeric_features = [
    "age",
    "weight",
    "troponin"
]

categorical_features = [
    "sex",
    "center",
    "diagnosis"
]
numeric_transformer = Pipeline(
    steps=[
        (
            "imputer",
            SimpleImputer(
                strategy="median"
            )
        ),
        (
            "scaler",
            StandardScaler()
        )
    ]
)

categorical_transformer = Pipeline(
    steps=[
        (
            "imputer",
            SimpleImputer(
                strategy="most_frequent"
            )
        ),
        (
            "encoder",
            OneHotEncoder(
                handle_unknown="ignore"
            )
        )
    ]
)
preprocessor = ColumnTransformer(
    transformers=[
        (
            "numeric",
            numeric_transformer,
            numeric_features
        ),
        (
            "categorical",
            categorical_transformer,
            categorical_features
        )
    ]
)

Pipeline completo con RBF

model = Pipeline(
    steps=[
        (
            "preprocessor",
            preprocessor
        ),
        (
            "classifier",
            SVC(
                kernel="rbf",
                C=1.0,
                gamma="scale",
                random_state=42
            )
        )
    ]
)

from sklearn.model_selection import GridSearchCV
from sklearn.model_selection import StratifiedKFold

cv = StratifiedKFold(

    shuffle=True,
    random_state=42

param_grid = [
    {
        "classifier__kernel": [
            "linear"
        ],
        "classifier__C": [
            0.01,
            0.1,

            10,
            100
        ]
    },
    {
        "classifier__kernel": [
            "rbf"
        ],
        "classifier__C": [

            1,
            10,
            100
        ],
        "classifier__gamma": [
            0.001,
            0.01,
            0.1,
            1,
            "scale"
        ]
    }
]
search = GridSearchCV(
    estimator=model,
    param_grid=param_grid,
    cv=cv,
    scoring="roc_auc",
    n_jobs=-1

search.fit(

    y_train
)

Mejor modelo

best_model = search.best_estimator_

print(

)

Evaluación de clasificación

from sklearn.metrics import roc_auc_score
from sklearn.metrics import average_precision_score
from sklearn.metrics import balanced_accuracy_score
from sklearn.metrics import classification_report

)

    X_test
)

roc_auc = roc_auc_score(

Clases desbalanceadas

model = SVC(
    kernel="rbf",
    C=1.0,
    gamma="scale",
    class_weight="balanced",
    random_state=42
)

También puede especificarse un peso manual:

class_weights = {
    0: 1,
    1: 3
}
model = SVC(
    class_weight=class_weights,
    random_state=42
)

Umbral de decisión

El umbral predeterminado de decision_function suele ser 0.

Puede modificarse:

threshold = -0.40

y_pred_threshold = (
    decision_score >= threshold
).astype(int)

Un umbral menor suele aumentar sensibilidad y reducir especificidad.

Calibración

Para decisiones clínicas conviene revisar si las probabilidades están calibradas.

from sklearn.calibration import CalibrationDisplay

CalibrationDisplay.from_predictions(
    y_test,
    y_probability,
    n_bins=10
)

plt.show()

SVM multiclase

SVC admite clasificación multiclase.

model = SVC(
    kernel="rbf",
    decision_function_shape="ovr",
    random_state=42
)

ovr significa one-vs-rest para la forma de la función de decisión expuesta.

Support Vector Regression

SVR adapta la idea de margen a problemas de regresión.

from sklearn.svm import SVR

model = SVR(
    kernel="rbf",
    C=1.0,
    gamma="scale",
    epsilon=0.1
)

Tubo epsilon-insensitive

SVR intenta colocar las predicciones dentro de un tubo de tolerancia.

       límite superior
----------------------------

        función estimada

----------------------------
       límite inferior

Los errores dentro del tubo no se penalizan de la misma manera.

Parámetro epsilon

epsilon=0.1

Controla el ancho del tubo.

Epsilon pequeño
→ ajuste más preciso
→ más support vectors
→ mayor sensibilidad al ruido

Epsilon grande
→ mayor tolerancia
→ modelo más simple

Pipeline de SVR

regression_model = Pipeline(
    steps=[
        (
            "preprocessor",
            preprocessor
        ),
        (
            "regressor",
            SVR(
                kernel="rbf",
                C=10,
                gamma="scale",
                epsilon=0.1
            )
        )
    ]
)

Evaluación de SVR

from sklearn.metrics import mean_absolute_error
from sklearn.metrics import root_mean_squared_error
from sklearn.metrics import r2_score

regression_model.fit(
    X_train,
    y_train
)

y_pred = regression_model.predict(
    X_test
)

mae = mean_absolute_error(
    y_test,
    y_pred
)

rmse = root_mean_squared_error(
    y_test,
    y_pred
)

r2 = r2_score(
    y_test,
    y_pred
)

param_grid = {

LinearSVR

Para regresión lineal en datasets más grandes:

from sklearn.svm import LinearSVR

model = LinearSVR(
    C=1.0,
    epsilon=0.1,
    random_state=42,
    max_iter=5000
)

Ventajas

  • Eficaz en espacios de alta dimensión.
  • Flexible mediante kernels.
  • Buena capacidad de generalización.
  • Útil con muestras pequeñas o moderadas.
  • Puede funcionar bien con muchas variables.
  • Permite clasificación y regresión.

Limitaciones

  • Necesita escalado.
  • Ajuste sensible de C y gamma.
  • Coste elevado en datasets grandes.
  • Menor interpretabilidad.
  • Probabilidades requieren calibración.
  • Puede ser difícil explicar decisiones individuales.
  • No maneja valores ausentes directamente.

Coste computacional

SVC con kernels puede ser costoso cuando aumenta el número de observaciones.

En datasets grandes pueden considerarse:

  • LinearSVC.
  • SGDClassifier.
  • Aproximaciones de kernels.
  • Modelos basados en árboles.
  • Muestreo o reducción dimensional.

Kernel approximation

from sklearn.kernel_approximation import Nystroem
from sklearn.linear_model import SGDClassifier

approximate_model = Pipeline(
    steps=[
        (
            "preprocessor",
            preprocessor
        ),
        (
            "kernel_map",
            Nystroem(
                kernel="rbf",
                gamma=0.1,
                n_components=300,
                random_state=42
            )
        ),
        (
            "classifier",
            SGDClassifier(
                loss="hinge",
                random_state=42
            )
        )
    ]
)

Interpretabilidad

En una SVM lineal pueden inspeccionarse los coeficientes.

linear_model = Pipeline(
    steps=[
        (
            "scaler",
            StandardScaler()
        ),
        (
            "classifier",
            LinearSVC(
                C=1.0,
                random_state=42
            )

    ]
)

    X_train,
    y_train
)

coefficients = (
    linear_model
    .named_steps["classifier"]
    .coef_[0]
)

En kernels no lineales la interpretación es más compleja.

Permutation importance

from sklearn.inspection import permutation_importance

permutation = permutation_importance(

La importancia explica la dependencia del modelo respecto a las variables, no causalidad.

Número de support vectors

Con un modelo SVC directo:

model.fit(
    X_train_scaled,
    y_train
)

Un número muy elevado puede indicar:

  • Frontera compleja.
  • Clases solapadas.
  • Ruido.
  • Regularización insuficiente.

scores = cross_validate(

Validación temporal

En un problema clínico longitudinal:

Train
→ periodo anterior

Test
→ periodo posterior

Esto ayuda a evaluar la capacidad de generalización futura.

Consideraciones clínicas

NoteAplicación clínica

Una SVM puede rendir bien, pero la dificultad para interpretar y calibrar sus predicciones debe considerarse antes de desplegarla.

Debe revisarse:

  • Sensibilidad y especificidad.
  • PR AUC en eventos raros.
  • Calibración.
  • Umbral de decisión.
  • Rendimiento por subgrupos.
  • Estabilidad entre centros.
  • Tiempo de inferencia.
  • Explicabilidad.

Errores frecuentes

  • No escalar las variables.
  • Escalar antes del split.
  • Ajustar C y gamma con test.
  • Interpretar decision_function como probabilidad.
  • Ignorar calibración.
  • Usar kernel RBF automáticamente.
  • No comparar con una SVM lineal.
  • No revisar desbalance.
  • Mezclar pacientes entre folds.
  • Utilizar demasiadas combinaciones en GridSearch.
  • No revisar tiempo computacional.
  • Interpretar importancia como causalidad.

Flujo recomendado

  1. Definir clasificación o regresión.
  2. Crear un baseline.
  3. Separar train y test.
  4. Integrar imputación y escalado en pipeline.
  5. Entrenar un modelo lineal.
  6. Comparar con kernel RBF.
  7. Ajustar C.
  8. Ajustar gamma o epsilon.
  9. Validar con folds adecuados.
  10. Revisar desbalance.
  11. Calibrar probabilidades cuando sea necesario.
  12. Evaluar una vez en test.
