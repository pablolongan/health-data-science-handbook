Machine Learning aplicado a datos de salud

Una guía personal y práctica para estudiar Health Data Science, consultar conceptos rápidamente y reutilizar código en proyectos clínicos y de investigación.

El contenido combina fundamentos estadísticos, preprocesamiento, evaluación de modelos, selección de variables, aprendizaje supervisado, reducción de dimensionalidad, series temporales, survival analysis y modelos multiestado.

Cómo utilizar este handbook

1. Comprender

Cada capítulo comienza con las ideas esenciales y la intuición necesaria para entender el método.

2. Aplicar

Los ejemplos de Python están pensados para copiarse y adaptarse a notebooks y proyectos reales.

3. Validar

Las páginas incluyen advertencias sobre leakage, validación, reproducibilidad y errores habituales.

4. Interpretar

Los ejemplos priorizan la interpretación clínica y las limitaciones de cada técnica.

NoteEnfoque del proyecto

Este handbook está diseñado como una referencia viva. Los capítulos pueden ampliarse con material del máster, ejercicios, notebooks, resultados y notas personales.

Principios del handbook

  • Separar correctamente train, validation y test.
  • Evitar data leakage en todas las fases.
  • Utilizar pipelines reproducibles.
  • Comparar con modelos baseline.
  • Evaluar discriminación, calibración y utilidad.
  • Interpretar los resultados dentro del contexto clínico.
  • Documentar cada decisión de análisis.
