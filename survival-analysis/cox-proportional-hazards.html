Modelo de riesgos proporcionales de Cox

TipResumen en 30 segundos

El modelo de Cox estudia la asociación entre covariables y el tiempo hasta un evento.

Su forma básica es:

\[ h(t\mid X) = h_0(t) \exp( \beta_1X_1+\cdots+\beta_pX_p ) \]

Permite:

  • Ajustar por varias variables.
  • Estimar hazard ratios.
  • Generar curvas de supervivencia ajustadas.
  • Predecir riesgo relativo.
  • Incorporar variables dependientes del tiempo.

Su supuesto principal es la proporcionalidad de riesgos.

¿Qué modela Cox?

El modelo de Cox relaciona las covariables con el hazard.

\[ h(t\mid X) = h_0(t) \exp( \beta^\top X ) \]

donde:

  • (h(tX)): hazard individual.
  • (h_0(t)): hazard basal.
  • (X): vector de covariables.
  • (): coeficientes.
NoteIdea clave

Cox no necesita especificar una forma paramétrica concreta para el hazard basal.

Modelo semiparamétrico

Se considera semiparamétrico porque:

  • La parte de covariables es paramétrica.
  • El hazard basal queda sin especificar.

Interpretación del coeficiente

Para una variable (X_j):

\[ HR_j = e^{\beta_j} \]

Hazard ratio

HR > 1
→ mayor hazard

HR < 1
→ menor hazard

HR = 1
→ ausencia de asociación

Ejemplo

HR = 1.40

Puede interpretarse como un hazard instantáneo aproximadamente un 40 % mayor por cada unidad de incremento, manteniendo constantes las demás variables.

Variable continua

Ejemplo:

Edad
HR = 1.03 por año

Un incremento de 10 años se interpreta como:

\[ HR_{10} = 1.03^{10} \]

Calcular HR para varias unidades

hr_per_year = 1.03

hr_per_10_years = (
    hr_per_year
    **
    10
)

Variable binaria

Ejemplo:

Tratamiento
0 = no
1 = sí

Un HR de 0.75 compara tratados frente a no tratados, condicionado al resto de covariables.

Variable categórica

Debe definirse una categoría de referencia.

Diagnóstico A
→ referencia

Diagnóstico B
→ HR respecto a A

Diagnóstico C
→ HR respecto a A

Preparar datos

cox_df = df[
    [
        "follow_up_days",
        "event",
        "age",
        "sex",
        "baseline_lvef",
        "treatment"
    ]
].copy()

Revisar missing

cox_df.isna().mean()

Codificar categóricas

cox_df = pd.get_dummies(
    cox_df,
    columns=[
        "sex",
        "treatment"
    ],
    drop_first=True
)

Ajustar modelo con lifelines

from lifelines import CoxPHFitter

cph = CoxPHFitter()
cph.fit(
    cox_df,
    duration_col="follow_up_days",
    event_col="event"
)

Resumen

cph.print_summary()

Resultados principales

El resumen incluye:

  • Coeficiente.
  • Hazard ratio.
  • Error estándar.
  • Intervalo de confianza.
  • Estadístico.
  • p-value.

Tabla de resultados

results = (
    cph.summary[
        [
            "coef",
            "exp(coef)",
            "se(coef)",
            "p",
            "exp(coef) lower 95%",
            "exp(coef) upper 95%"
        ]
    ]
)

Interpretar intervalo de confianza

Ejemplo:

HR = 1.40
IC 95 %: 1.10 a 1.78

El intervalo no incluye 1, por lo que existe evidencia estadística de asociación bajo el modelo.

No interpretar solo p-value

Debe considerarse:

  • Magnitud.
  • Intervalo.
  • Plausibilidad.
  • Confusión.
  • Calidad de datos.
  • Supuestos.
  • Relevancia clínica.

Función de hazard basal

baseline_hazard = (
    cph.baseline_hazard_
)

Hazard acumulado basal

baseline_cumulative_hazard = (
    cph.baseline_cumulative_hazard_
)

Supervivencia basal

baseline_survival = (
    cph.baseline_survival_
)

Score de riesgo relativo

partial_hazard = (
    cph.predict_partial_hazard(
        cox_df
    )
)

Valores mayores indican mayor riesgo relativo.

Predicción de supervivencia

survival_function = (

patient_profiles = cox_df.iloc[

Selección de covariables

La selección debe basarse en:

  • Pregunta clínica.
  • Confusores conocidos.
  • Evidencia previa.
  • Disponibilidad.
  • Número de eventos.
  • Riesgo de colinealidad.
  • Parsimonia.

No seleccionar solo por p-value univariable

Una variable no significativa de forma univariable puede ser un confusor importante.

Modelo univariable

univariable_df = cox_df[
    [
        "follow_up_days",
        "event",
        "age"
    ]
]
univariable_model = CoxPHFitter()

univariable_model.fit(
    univariable_df,
    duration_col="follow_up_days",
    event_col="event"
)

Modelo multivariable

multivariable_model = CoxPHFitter()

multivariable_model.fit(
    cox_df,
    duration_col="follow_up_days",
    event_col="event"
)

Confusión

Una covariable es confusora cuando se relaciona con:

  • Exposición.
  • Outcome.
  • No es consecuencia de la exposición.

Ajuste excesivo

Puede ocurrir al incluir:

  • Mediadores.
  • Variables posteriores.
  • Variables casi duplicadas.
  • Demasiadas covariables para pocos eventos.

Eventos por variable

Reglas simples como 10 eventos por parámetro se usan como orientación, no como ley universal.

Debe considerarse:

  • Complejidad.
  • Penalización.
  • Colinealidad.
  • Distribución.
  • Validación.

Colinealidad

Ejemplos:

  • Edad y edad al diagnóstico.
  • FEVI Simpson y FEVI modo M.
  • Peso y superficie corporal.
  • Troponina y daño miocárdico derivado.

Revisar correlaciones

correlation_matrix = (

VIF

from statsmodels.stats.outliers_influence import variance_inflation_factor

X = cox_df.drop(

vif_table = pd.DataFrame(
    {
        "feature": X.columns,
        "vif": [
            variance_inflation_factor(
                X.values,
                index
            )
            for index in range(
                X.shape[
                    1
                ]
            )
        ]
    }
)

Escalado de variables

No es obligatorio para Cox clásico, pero puede facilitar:

  • Comparabilidad.
  • Penalización.
  • Convergencia.
  • Interpretación por desviación estándar.

Estandarizar

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

cox_df[
    [
        "age",
        "baseline_lvef"
    ]
] = scaler.fit_transform(
    cox_df[
        [
            "age",
            "baseline_lvef"
        ]
    ]
)

Interpretación tras estandarizar

El HR corresponde a un incremento de una desviación estándar.

No linealidad

Cox asume linealidad de las covariables continuas en el log-hazard.

Edad
→ efecto lineal sobre log-hazard

Esto puede ser incorrecto.

Categorizar continuas

cox_df[
    "age_group"
] = pd.cut(
    cox_df[
        "age"
    ],
    bins=[
        0,
        40,
        60,
        80,
        float(
            "inf"
        )
    ]
)

Categorizar pierde información y crea puntos de corte artificiales.

Splines

Los splines permiten relaciones no lineales.

cph = CoxPHFitter()
cph.fit(
    cox_df,
    duration_col="follow_up_days",
    event_col="event",
    formula=(
        "bs(age, df=4)"
        " + baseline_lvef"
        " + treatment"
    )
)

Interacciones

cox_df[
    "age_x_treatment"
] = (
    cox_df[
        "age"
    ]
    *
    cox_df[
        "treatment_yes"
    ]
)

Interacción clínica

Puede representar que el efecto de una variable cambia según otra.

Ejemplo:

Efecto del tratamiento
→ diferente según edad

Interpretar interacciones

Con interacción, los efectos principales no deben interpretarse de forma aislada.

Estratificación

Si una variable incumple proporcionalidad, puede utilizarse como estrato.

cph.fit(
    cox_df,
    duration_col="follow_up_days",
    event_col="event",
    strata=[
        "center"
    ]
)

Qué hace la estratificación

Permite que cada estrato tenga su propio hazard basal.

Pero no estima un HR para la variable estratificada.

Ejemplo por centro

Centro A
→ hazard basal propio

Centro B
→ hazard basal propio

Penalización

Puede utilizarse cuando:

  • Hay muchas covariables.
  • Hay colinealidad.
  • Hay pocos eventos.
  • Se necesita estabilidad.

Ridge en Cox

cph = CoxPHFitter(
    penalizer=0.1,
    l1_ratio=0.0
)

Lasso en Cox

cph = CoxPHFitter(
    penalizer=0.1,
    l1_ratio=1.0
)

Elastic Net

cph = CoxPHFitter(
    penalizer=0.1,
    l1_ratio=0.5
)

Elegir penalización

Debe seleccionarse mediante validación interna adecuada.

Cluster robust standard errors

Cuando existen observaciones agrupadas:

  • Paciente.
  • Hospital.
  • Familia.
  • Centro.

pueden utilizarse errores robustos.

cph.fit(
    cox_df,
    duration_col="follow_up_days",
    event_col="event",
    cluster_col="center_id",
    robust=True
)

Frailty

Los modelos de frailty incorporan heterogeneidad no observada compartida.

Ejemplos:

  • Centro.
  • Familia.
  • Paciente con eventos recurrentes.

Cox y tiempo dependiente

Para covariables temporales se utiliza formato start-stop.

patient_id | start | stop | event | treatment

Ajustar modelo temporal

from lifelines import CoxTimeVaryingFitter

ctv = CoxTimeVaryingFitter()
ctv.fit(
    interval_df,
    id_col="patient_id",
    start_col="start",
    stop_col="stop",
    event_col="event"
)

Supuesto de riesgos proporcionales

El modelo asume:

\[ \frac{ h(t\mid X_a) }{ h(t\mid X_b) } = \text{constante en }t \]

Violación del supuesto

Ejemplo:

Tratamiento beneficioso al inicio
→ efecto desaparece después

En ese caso, un único HR puede ser engañoso.

Revisar supuesto

cph.check_assumptions(
    cox_df,
    p_value_threshold=0.05,
    show_plots=True
)

Residuos de Schoenfeld

Se utilizan para evaluar si el efecto de una covariable cambia con el tiempo.

Soluciones ante incumplimiento

  • Estratificación.
  • Interacción con tiempo.
  • Coeficientes dependientes del tiempo.
  • Dividir periodo.
  • Modelos paramétricos flexibles.
  • RMST.
  • Modelos AFT.

Interacción con tiempo

cox_df[
    "treatment_log_time"
] = (
    cox_df[
        "treatment_yes"
    ]
    *
    np.log1p(
        cox_df[
            "follow_up_days"
        ]
    )
)

Debe implementarse con una estructura y formulación adecuadas, evitando usar tiempo final como covariable basal de forma ingenua.

Ties

Los empates ocurren cuando varios eventos tienen el mismo tiempo.

Son frecuentes con fechas registradas por día.

Los métodos de aproximación incluyen:

  • Breslow.
  • Efron.
  • Exacto.

Predicción absoluta

El HR es relativo.

Para obtener riesgo absoluto se necesita:

  • Hazard basal.
  • Horizonte.
  • Perfil de covariables.

Supervivencia individual

\[ S(t\mid X) = S_0(t)^{ \exp( \beta^\top X ) } \]

Curvas ajustadas por perfiles

Puede compararse:

Paciente de bajo riesgo
Paciente de riesgo medio
Paciente de alto riesgo

manteniendo definidos los perfiles.

Curvas estandarizadas

Para comparar grupos ajustados puede promediarse la supervivencia predicha sobre una población común.

Evaluación del modelo

Debe incluir:

  • Discriminación.
  • Calibración.
  • Rendimiento temporal.
  • Validación externa.
  • Supuestos.
  • Estabilidad.

Concordance index

concordance = (
    cph.concordance_index_
)

Limitaciones del C-index

  • No mide calibración.
  • Puede ser optimista.
  • No refleja horizontes concretos.
  • No indica utilidad clínica.

Validación interna

Opciones:

  • Bootstrap.
  • Cross-validation.
  • Penalización.
  • Corrección de optimismo.

Cross-validation

from lifelines.utils import k_fold_cross_validation

scores = k_fold_cross_validation(
    cph,
    cox_df,
    duration_col="follow_up_days",
    event_col="event",
    k=5,
    scoring_method="concordance_index"
)

Limitación del k-fold aleatorio

Si existe estructura temporal o multicentro, el split debe reflejarla.

Validación temporal

Periodo antiguo
→ desarrollo

Periodo posterior
→ validación

Validación externa

Centro A
→ desarrollo

Centro B
→ validación

Bootstrap

Puede utilizarse para:

  • Optimismo.
  • Estabilidad de coeficientes.
  • Intervalos.
  • Selección de variables.

Calibration curve

Debe compararse supervivencia predicha y observada en tiempos concretos.

Ejemplo:

Supervivencia predicha a 1 año
vs
Kaplan-Meier observada a 1 año

Modelos explicativos y predictivos

Explicativo

Objetivo:

  • Estimar asociaciones.
  • Controlar confusión.
  • Interpretar HR.

Predictivo

Objetivo:

  • Predecir riesgo individual.
  • Maximizar rendimiento.
  • Evaluar calibración y validación.

Las decisiones metodológicas pueden diferir.

Causalidad

Un HR ajustado no demuestra causalidad.

Puede persistir:

  • Confusión residual.
  • Sesgo de selección.
  • Confounding by indication.
  • Medición imperfecta.
  • Variables no observadas.

Reporting

Debe incluir:

  • Población.
  • Tiempo cero.
  • Evento.
  • Censura.
  • Número de eventos.
  • Covariables.
  • Missing.
  • HR e intervalos.
  • Supuestos.
  • Validación.
  • Métricas.

Consideraciones clínicas

NoteAplicación clínica

El modelo de Cox es adecuado para estudiar asociaciones ajustadas y estimar supervivencia individual cuando sus supuestos son razonables.

Debe revisarse:

  • Tiempo cero.
  • Confusores.
  • Forma funcional.
  • Proporcionalidad.
  • Eventos por parámetro.
  • Calibración.
  • Validación externa.

Errores frecuentes

  • Interpretar HR como riesgo absoluto.
  • Seleccionar variables solo por p-value.
  • No comprobar proporcionalidad.
  • Categorizar continuas sin necesidad.
  • Incluir mediadores.
  • Usar variables futuras.
  • Ignorar colinealidad.
  • Sobreajustar con pocos eventos.
  • Reportar solo C-index.
  • No evaluar calibración.
  • Interpretar asociación como causalidad.
  • No validar externamente.

Flujo recomendado

  1. Definir pregunta.
  2. Seleccionar covariables.
  3. Revisar missing.
  4. Revisar colinealidad.
  5. Ajustar modelo.
  6. Interpretar HR.
  7. Revisar forma funcional.
  8. Comprobar proporcionalidad.
  9. Revisar residuos.
  10. Evaluar discriminación.
  11. Evaluar calibración.
  12. Validar externamente.
